# Journal du 2026-11-12

## Reprise : #332 terminée

La PR #332 (blocs de code défilants, « Refs #210 ») était restée ouverte, e2e rouge depuis le
2026-11-05 : `scrollable-region-focusable` et espacement du texte sur `/components/diff/` à 375 px.
Cause : le `pre` nu interne du composant `Diff` recevait la règle `.docs-main pre:not([class])`
et devenait une seconde région défilante, sans focus, dans `.pp-diff-scroll` qui a déjà
`tabindex="0"`. Correctif : `:not(.pp-diff-scroll > pre)` dans `code.css`, deux références
Visuel du diff rétablies à celles de `main`. CI verte, fusionnée (squash).
