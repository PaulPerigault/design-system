## Composant Astro `Milestones3D` (#363, PR #371)

Branche `feat/363-composant-milestones-3d`. Composant, comportement (`milestones-3d.ts`, `-gate.ts`,
`-view.ts`, `-types.ts`), styles dans `@paulperigault/css`, fragment de registre, 55 tests.

Défauts tranchés : langue des dates par la prop `locale` (défaut `fr`), mots d'interface par la
prop `labels` (défaut français), comportement importable seulement avec le paquet 3D installé.
Le test de l'échappement de `<` dans le bloc de données a trouvé une perte de la séquence
d'échappement à l'écriture du fichier : corrigé avant la PR.

Écart : `peerDependencies` facultative non ajoutée, `package-lock.json` est en écriture interdite
pour cette session (refus des permissions, non contourné). À faire avec le lockfile.

Incident de CI : modifier le corps de la PR pendant la CI annule `e2e` et `visuel` du run de code
(concurrence) et l'agrégat `ci` du run `edited` échoue ensuite sur ces contrôles annulés. Remède :
relancer le run de code. Règle de la session : le corps de la PR est écrit avant le premier envoi.

## Page de documentation et démonstration (#364)

Branche `docs/364-page-milestones-3d`. Page `/components/milestones-3d/` : démonstration en deux
exemplaires (classique, amélioré), sections propres à la page insérées avant « Preuves et
décisions » par un slot `more` et la prop `extra` de `ComponentPage` : conditions de chargement,
données, politique de sécurité à prévoir, poids mesurés.

Constat de build : le `.wasm` n'est jamais commité et le build Cloudflare n'a pas cargo. Sans lui,
le build de la doc réussit (avertissement Vite sur `new URL`) et la page affiche la liste seule,
avec une note qui le dit. Avec lui, il est émis dans `_astro/` (cache immutable) et la 3D s'active.
Le serveur de test n'avait pas le type `application/wasm` : ajouté. Un canvas WebGL2 qui ne fait que
`clear` émet « GPU stall due to ReadPixels » sous Chromium headless (rastériseur logiciel) : exclu du
contrôle console avec la preuve en commentaire.

Part mondiale de WebGL2 : non chiffrée, aucune source lisible (`caniuse-lite` absent du dépôt).
Poids : relevé du 2026-11-19 (README du paquet) et relevé du build de la doc du 2026-11-20.
