## Correctif CI : `ci` d'un run `edited` masquait un run de code (#71)

- Constat sur la PR #124 : le filtre `changes` est correct (e2e et Visuel ont tourné sur le run de
  code). Le run `edited` (titre modifié) saute e2e et Visuel à dessein, mais publie son propre `ci`,
  vert, sur le même SHA : la fusion (17:09) a eu lieu pendant que Visuel tournait encore, et Visuel
  a échoué à 17:11.

  SHA (API check-runs) et échoue s'ils ont échoué ; permission `checks: read` limitée à ce job.
