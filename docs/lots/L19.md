# Lot L19 — composants de niveau 2 (2/2)

## Produit

Huit composants : Tabs, Menu (navigation), Popover, Tooltip (surcouches), Toast, Combobox, CodeBlock
et Diagram. Chacun a un test, une page au gabarit L13, un fragment de registre et passe axe, reflow
et espacement du texte sur 13 appareils.

- Tabs : sans JavaScript, des sections lisibles ; le script les transforme en onglets APG.
- Popover et Menu : API HTML `popover`, ancrage CSS avec repli sous le bouton.
- Tooltip : conforme 1.4.13 (Échap, survol de l'infobulle, persistance).
- Toast : minuteur suspendu au survol et au focus (2.2.1), fonctions importées, aucun global.
- Combobox : motif APG List Autocomplete, repli `<datalist>` sans JavaScript. Le champ envoie le
  libellé, pas la valeur de l'option (dit dans la page).
- CodeBlock : coloration au build par `shiki` 4.5.0 (nouvelle dépendance, exacte) avec thème à
  variables CSS, jetons rendus en `data-tok` : aucun attribut `style`.
- Diagram : enveloppe SVG accessible (`title`, `desc`), option défilable.

## Décisions

- Barre d'onglets mobile en bas : écartée, comme `docs/benchmark/gap.md` n° 3 (31+ pages, masque le
  contenu, conflit avec la barre du navigateur). Le menu modal reste la navigation mobile.
- « Badge d'état » : déjà couvert par `Status`.

## Leçons

- Les gardes de conception (`check:guards`, propriétés physiques) ne figuraient pas dans
  l'acceptation des tâches : à ajouter (`npm run check:guards`).
- Poser navigation, exports, stubs de page et fragment de registre avant le lot a réglé le blocage
  de L18. À garder.
- Les revues croisées de Combobox (Opus, gpt-5.6-terra) n'ont rendu aucun verdict lisible
  (permissions refusées en mode non interactif) ; l'orchestrateur a relu `combobox.ts` lui-même.
  Le comportement clavier est testé en logique pure, pas au clavier réel dans un navigateur.
- Le contrôle 1.4.12 du dépôt mesure `clientWidth` : sans objet pour le texte SVG. Il l'ignore
  maintenant, après vérification par capture avec l'espacement imposé.

## Coût

Huit tâches : sonnet-5.5 sur Tabs (10,2), Popover (3,3), Tooltip (4,5), Toast (12,4), Menu (14,4),
CodeBlock (11,3) ; haiku-5.5 sur Diagram (1,6) ; opus-5.5 sur Combobox (30,6). Total ≈ 88 crédits,
sans escalade. Trois échecs apparents (Tabs, Popover, Tooltip) venaient d'un bit exécutable posé sur
`pp-mcp.mjs` par npm dans le worktree, pas du code.
