# Lot L7 — documentation, accessibilité sur toutes les pages, registre

## Produit

- Sommaire des 31 composants (`apps/docs/src/navigation.ts`, source unique du menu et de
  l'accueil), lien « Composants » dans l'en-tête ; e2e : le sommaire liste exactement les pages
  construites.
- e2e sur **toutes** les pages construites, lues dans `dist/` (échec fermé sans build) : axe
  (WCAG 2.2 A et AA) × 2 thèmes × 2 fenêtres, espacement du texte (1.4.12), tailles de cibles

- Assembleur du registre (`tools/registry`) : `meta.tokens` recalculés depuis les fichiers
  (valeurs de base **et** rôles des thèmes), fichiers déclarés vérifiés, chaque export `.astro`
  couvert, `registry.json` (schéma shadcn) écrit ; `npm run registry`, `check:registry` dans
  `guard`. Les 10 fragments manquants de L5 et celui d'InvokerFallback sont créés.
- `check-design` : règle `physical-property` (déclarations physiques refusées au profit des
  propriétés logiques ; conditions `@media`/`@container` non visées).
- `InvokerFallback` : repli des Invoker Commands et de `closedby="any"`, script externe inactif là
  où le navigateur les gère ; e2e de Dialog (clavier, focus rendu, fermeture, clic hors boîte,
  API masquées, un seul script chargé et seulement sur ses pages).
- Mesure recalibrée de 38 à 36 rem (D-017) : 69,7 caractères en moyenne par ligne pleine,
  mesurés dans le navigateur avec la vraie police.
- `layout.spec.ts` resserré : gap de Cluster, largeur de Container et de Center comparés aux
  valeurs résolues des tokens.

## Relecture (T7.05)

Aucun bloquant ; un point important fondé : l'e2e du repli ne prouvait rien, Chromium gardant son
comportement natif même propriétés JS supprimées. Corrigé par un compteur des appels JS à
`showModal` (1 en repli, 0 en natif : le script reste inactif là où l'API existe). Appliqués
aussi : focus donné au déclencheur avant l'ouverture (Safari ne le donne pas au clic),
`preventDefault` quand une commande est jouée, clic hors boîte seulement si l'appui y a aussi
commencé, commande sans casse. Le clic hors boîte en repli n'est pas prouvable dans Chromium (il
ferme au relâché, avant le clic) : couvert par les tests unitaires.

## Écarts et reste à faire

- Tableaux de propriétés : 28 pages gardent un `<table>` écrit à la main, aux colonnes variables
  (« Propriété/Valeurs/Défaut », « Prop/Type/Description »…). Ils passent 1.4.12 aujourd'hui ;
  un composant de doc commun sur `Table` les uniformiserait.
- Mineurs de L6 non repris : `sizes` du dialogue d'agrandissement (`page`), collision possible
  d'identifiants entre deux galeries aux préfixes proches, cache de `dominantColor` par chemin
  seul (couleur figée en `astro dev` seulement).
- Règle `physical-property` limitée aux déclarations CSS : les classes Tailwind physiques
  (`ml-*`, `pl-*`, `text-left`…) ne sont pas encore visées.
- Étape mécanique `eslint --fix` du dispatcher : sans objet depuis l'arrêt de Kiro.
