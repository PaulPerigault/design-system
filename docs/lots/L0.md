# Lot L0 — vérifications, squelette, CI, agents, dispatcher

Exécuté par l'orchestrateur (Claude Opus 5.5) : 100 % Claude, 0 % Kiro (lot structurant, le
dispatcher n'existait pas encore). Seuls appels Kiro : vérifications (Haiku, < 0,1 crédit).

## Produit

- Monorepo npm workspaces : 5 paquets `@paulperigault/*` (manifestes, `publishConfig` npmjs,
  provenance, garde `prepublishOnly`) et `apps/docs` (Astro, build statique).
- Outillage : ESLint (règles de conception du portfolio), Prettier, Vitest par projets, Husky,
  commitlint avec règle `no-tool-signature` sans exemption, `check-size`, `check-lockfile`.
- Règles : `AGENTS.md` (source unique), `CLAUDE.md`, `.kiro/steering/ds.md`, ADR-0001.
- Garde-fous de l'assistant : `.claude/settings.json` (attribution vide, 167 refus),
  hooks `tools/guards/guard-npm-publish.mjs` et `guard-pr-merge.mjs`, testés.
- Agents Kiro `ds-worker` et `ds-reviewer` (format V3, refus par `permissions.rules`, hook
  `PreToolUse`), validés par `kiro-cli agent validate`.
- Dispatcher `tools/agents/` (run, batch, review, integrate) et 110 tests.
- CI : `ci.yml` (commitlint de la plage et du titre + corps de la PR, `verify`, zizmor, agrégat
  `ci`), `release.yml` (release-please manifest monorepo + publication OIDC, inerte sans `main`),
  Dependabot.

## Vérifier

```shell
npm ci
npm run verify
for a in ds-worker ds-reviewer; do kiro-cli agent validate --path .kiro/agents/$a.json; done
npx vitest run --project tools
```
