## Produit

- `/llms.txt` (format llmstxt.org), `/llms-full.txt` et une version Markdown de chaque page
  (`/components/button.md`), produites après `astro build` par `apps/docs/scripts/markdown.mjs`.

  (contenu des fichiers en ligne, `target` d'installation). Vérifié avec `npx shadcn@latest` sur
  un `components.json` de test : `view @pp/button` et `search @pp` (32 éléments) fonctionnent. Le
  MCP de shadcn s'appuie sur la même déclaration de registre (non lancé : il demande un client MCP).

  `list_components`, `get_component`, `get_tokens`, `check_contrast` (WCAG 2 et APCA informatif),
  `validate_snippet` (garde-fous de `@paulperigault/guards`), `search_docs`, `get_decision`.
  Données embarquées (`data/*.json`) générées par `build-data.mjs`, dérive contrôlée par
  `check:mcp-data` après le build. 77 tests.
- ADR-0003 : MCP stdio maintenant, version distante seulement planifiée.
- Gabarit `create` : `.mcp.json`, `.kiro/settings/mcp.json`, `.cursor/mcp.json` et `AGENTS.md`
  dans le site généré, `@paulperigault/mcp` en `devDependency`.
