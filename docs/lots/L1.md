# Lot L1 — pilote Stack via Kiro

Objectif : valider le dispatcher de bout en bout (worktree, `npm ci`, Kiro headless, acceptation,
contrôle de propriété, résultat, revue, intégration) sur une tâche simple.

## Produit

- `packages/astro/src/layout/Stack.astro` : primitive « Every Layout », sans JS, sans attribut
  `style` (variante `data-space` mappée en CSS), enfants du slot visés par `:global()`.
- Test de rendu (21 tests), fragment de registre `stack.json`, page `apps/docs` `/components/stack/`.
- Dispatcher amélioré : formatage des fichiers possédés avant acceptation (D-006), verdict de
  revue robuste (D-007), branche d'intégration par lot (D-008), `renderDom` corrigé.
