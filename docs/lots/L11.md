# Lot L11 — référentiel

## Produit

`docs/benchmark/` : base de référence de la phase 2.

- `norms.md` : WCAG 2.2 AA + quatre critères AAA retenus ; WCAG 3 en veille (brouillon du
  3 mars 2026) ; RGAA 4.1 en vigueur (RGAA 5 annoncé pour fin 2026) ; EN 301 549 V4.1.1
  (septembre 2026, WCAG 2.2 intégral) ; Acte européen non applicable au portfolio ni à la doc.
- `science.md` : Hoober 2013 et 2017, Parhi et al. 2006, Dyson & Haselgrove 2001, seuils des Core
  Web Vitals, Web Almanac 2025, WebAIM Million 2026, StatCounter (septembre 2026 : 59 % mobile),
  classés prouvé, convention, préférence.
- `systems.md` : Material 3 (Expressive), Apple HIG, Primer, Polaris (web components), Carbon,
  Atlassian, Fluent 2, GOV.UK Frontend v6, DSFR 1.15, Radix et Base UI, shadcn/ui ; outillage IA
  (MCP de Primer, Carbon et shadcn).
- `panel.md` : 32 acteurs ; 19 observés, 9 refusent les robots, 4 ont une protection anti-robot ;
  publié et observé séparés.
- `gap.md` : 30 pratiques, décision motivée pour chacune ; définit L12 (20 lignes), L13 (7), L14 (3).
- `tools/benchmark/` : observation Playwright avec `robots.txt` (RFC 9309) et arrêt sur page
  protégée ; résumé chiffré ; tests.

## Écarts

- Core Web Vitals réels par site non relevés : PageSpeed Insights sans clé a répondu HTTP 429 ;
  remplacés par les agrégats du Web Almanac 2025.
- Première passe d'observation jetée (bannières de consentement comptées comme navigation) ;
  la seconde les exclut. Une page et un passage par acteur : des indices, pas une note.
