# Lot L16 — site vitrine

## Produit

- Socle SEO (`SeoHead`, `lib/seo.ts`) : titre et description uniques, canonical, Open Graph,
  JSON-LD (`Person`, `WebSite`, `BreadcrumbList`, `TechArticle`), `sitemap.xml`, `robots.txt`.
- Pages : accueil-manifeste, architecture (schéma SVG), décisions (ADR rendues), preuves (chiffres
  lus dans `src/data/proofs.json`), auteur, utiliser, mentions légales, confidentialité, crédits.
- `legal.ts` : le build de production échoue si l'hébergeur ou le contact est vide
  (`PP_PRODUCTION=1`). Zéro cookie, zéro traceur, prouvé par `csp.spec.ts`.
- Les textes à la première personne portent `DraftNotice` : brouillons à relire par Paul.

## Coût et routage

Dix tentatives, 24,3 crédits. Sept tâches sur sept aux paliers économiques à la première
tentative : 4 réussies (haiku-5.5), 3 escaladées à Sonnet 5.5 pour `astro check`, lectures refusées
et ESLint. Le multiplicateur de crédits ne prédit pas le résultat (D-022).
