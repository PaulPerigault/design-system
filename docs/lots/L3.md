# Lot L3 — primitives de layout

## Produit

- `@paulperigault/astro` : Cluster, Grid, Container, Sidebar, Switcher, Center (« Every Layout »),
  en plus de Stack (L1) et de `variants()` (livrée en L2). Sans JavaScript, sans attribut
  `style` (variantes `data-*`), enfants de slot visés par `:global()`, propriétés logiques,
  `role="list"` pour les listes sans puces, `label` pour les `nav`.
- Exports du paquet pour les primitives et les composants de formulaire (fichier partagé).
- Fragments de registre des six primitives (`meta.tokens` vérifiés contre les sources).
- Doc : une page par primitive ; e2e `layout.spec.ts` qui vérifie le **CSS appliqué** par
  valeurs (marge du 2e enfant de Stack = `--pp-space-m`, 1er enfant 0…), ce qui attrape le défaut
  du pilote T1.01.
