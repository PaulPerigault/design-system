# Lot L5 — retour et structure

## Produit

- `src/feedback/` : Alert (ton écrit en clair, rôle seulement si `live`), Progress (progress et
  meter natifs, valeur en texte relié), Dialog (`<dialog>` modal, ouverture par Invoker Commands
  sans script, `closedby="any"`, `::backdrop` sans flou, entrée sous `no-preference`), Status
  (statut de pipeline, forme d'icône propre à chaque état, mono facultative).
- `src/content/` : Separator, Accordion (`<details name>` natif, animation progressive), Table
  (région défilante nommée et focalisable), Breadcrumb (`aria-current`, `role="list"`), Prose
  (contenu éditorial par `:global()`), Diff (`<ins>`/`<del>` natifs, signes visibles, libellés lus).
- Exports déclarés **avant** les tâches ; dispatcher : contrôle préalable affiné (dossiers créés
  ignorés), amorce corrigée (cible remplacée, plus d'imbrication `node_modules/node_modules`).
