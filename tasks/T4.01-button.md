Composant **natif** (zéro JavaScript), accessible (WCAG 2.2 AA), dans `packages/astro/src/forms/`.
Lis d'abord `AGENTS.md`, `packages/astro/src/layout/Stack.astro` (modèle de props, variantes
`data-*`, **aucun attribut `style`**, `:global()` pour le contenu de slot) et
`packages/astro/src/lib/variants.ts` (classes de variantes). Tokens `--pp-*` uniquement (liste :
`packages/tokens/generated/tokens.json`) : hauteur des contrôles `--pp-size-control-height`,
cible minimale `--pp-size-target-min`, bordure `--pp-color-control` (3:1), focus hérité de
`@paulperigault/css` (ne pas le redéfinir), rayon `--pp-radius-control`, propriétés logiques.
**Aucun texte en dur** : tout libellé vient des props (le site traduit). Export
`@paulperigault/astro/Button.astro` : à demander (fichier partagé), les tests importent le fichier
par chemin relatif.

## Button

`<button>` (défaut `type="button"`) ou `<a>` si `href` est fourni (mêmes classes). Props :
`tone?: 'primary' | 'secondary' | 'quiet'` (défaut `primary` : fond accent, texte
`--pp-color-on-accent` ; `secondary` : bordure contrôle ; `quiet` : sans bordure, souligné),
`size?: 'm' | 'l'`, `type?`, `disabled?` (pour `<a>` : pas de `href`, `aria-disabled="true"`),
`href?`, `class?`. Classes via `variants()`. Hauteur minimale `--pp-size-control-height`.
Transitions sur `--pp-duration-fast` uniquement (nulles sous `reduce` via les tokens).

Test `packages/astro/test/Button.test.ts` (`renderDom` de `./render`) : rôles et noms accessibles,
attributs ARIA selon les props, valeurs par défaut, aucun attribut `style`. Page de doc
`apps/docs/src/pages/components/button.astro` sur `../../layouts/DocsLayout.astro` : exemples
(défaut, erreur, désactivé), tableau des props, une phrase factuelle d'usage.
