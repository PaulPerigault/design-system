Socle partagé des contrôles de `@paulperigault/guards` (`check-design`, `check-size`,
`check-layers`, `check-images`, écrits ensuite en parallèle sur ce socle). Fichiers `.mjs`, JSDoc,
aucune dépendance d'exécution (seulement `node:*`). Ne touche pas `src/check-tokens.mjs`.

## Contrat d'entrées-sorties (`src/lib/io.mjs`)

Typedef JSDoc `GuardIo`, que tous les contrôles reçoivent :

```js
/** @typedef {object} GuardIo
 * @property {(path: string) => string} readText      // UTF-8
 * @property {(path: string) => Uint8Array} readBytes
 * @property {(dir: string) => { name: string, isDirectory: () => boolean }[]} readdir
 * @property {(path: string) => number} size          // octets
 * @property {(path: string) => boolean} exists
 * @property {(message: string) => void} out
 * @property {(message: string) => void} err
 */
```

et `nodeIo({ stdout, stderr })` : implémentation réelle (`node:fs` synchrone, `withFileTypes`),
écrit `message + '\n'` sur les flux reçus. Les chemins sont POSIX, relatifs au dossier courant.

## `src/lib/files.mjs`

- `SKIPPED_DIRS` : `node_modules`, `dist`, `.astro`, `.git`, `coverage`, `test-results`,
  `playwright-report`.
- `listFiles(io, roots, { extensions, skip = SKIPPED_DIRS })` : fichiers des racines (récursif),
  extension comparée en minuscules (`.JPG` = `.jpg`), triés, sans doublon ; une racine absente
  (`io.exists` faux) est ignorée sans erreur ; une racine qui est un fichier est retenue telle quelle
  si son extension convient.
- `lineOf(text, index)` : numéro de ligne (1 = première) d'un index de caractère.

## `src/lib/paths.mjs`

- `normalizePath(path)` : POSIX, sans `./` initial ni `/` final, `\` → `/`.
- `matchesPath(file, entry)` : vrai si la suite de segments de `entry` apparaît dans celle de
  `file`, segments entiers. `src/media` couvre `src/media/a.astro` et
  `packages/astro/src/media/a.astro`, pas `src/mediakit/a.astro` ; une entrée qui est un chemin de
  fichier complet le couvre aussi.
- `matchesAny(file, entries)`.

## `src/lib/report.mjs`

- Un problème = `{ file, line?, message }`.
- `report(io, { name, problems, checked })` : chaque problème sur `io.err` au format
  `fichier:ligne: message` (sans `:ligne` si `line` absent), puis une ligne de synthèse sur `io.out` :
  `<name> : OK (<checked> fichiers)` ou `<name> : <n> problème(s) sur <checked> fichiers`.
  Retourne `0` sans problème, `1` sinon.
- `class GuardUsageError extends Error` : erreur d'usage ou de configuration (code de sortie 2).

## `test/fake-io.mjs`

`fakeIo(files)` où `files` = `{ 'chemin/a.css': 'texte' | Uint8Array }` : rend
`{ io, out: string[], err: string[] }`, dossiers déduits des chemins, `size` = octets réels
(texte encodé en UTF-8). Ce fichier n'est pas un `*.test.mjs` : les règles ESLint complètes s'y
appliquent (pas de nombre magique).
