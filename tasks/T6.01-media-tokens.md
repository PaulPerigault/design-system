Ajoute les tokens média au format DTCG 2025.10, puis régénère `generated/` avec
`npm -w @paulperigault/tokens run build` (ne jamais éditer `generated/` à la main). Lis d'abord
`AGENTS.md`, `packages/tokens/src/tokens/*.json`, `packages/tokens/test/source.test.mjs` et
`packages/tokens/test/contrast-matrix.test.mjs`. Le générateur ne gère pas les alias `{…}` : les
valeurs égales à un autre token sont recopiées et leur égalité est **testée**.

## Dans `base.tokens.json` : groupe `media` (exactement ces noms et valeurs)

Chemin, `$type`, `$value`, puis `$description` à reprendre :

- `media.radius`, `dimension`, `0.5 rem` : « Rayon des médias ; égal à `radius.surface`. »
- `media.rule`, `dimension`, `1 px` : « Épaisseur du filet média ; égale à `size.rule`. »
- `media.budget.hero`, `number`, `200` : « Poids maximal d'une variante générée, en Ko
  (préférence). » ; `media.budget.card` : `80` ; `media.budget.gallery` : `150` (même texte).
- `media.scrim.color`, `color`, OKLCH `[0.201, 0.0124, 270.7]` (encre) : « Voile sous un texte
  posé sur une photo ; identique dans les deux thèmes. »
- `media.scrim.text`, `color`, OKLCH `[0.995, 0.002, 270.7]` : « Texte posé sur le voile. »
- `media.scrim.opacity`, `number`, `0.72` : « Opacité du voile (contraste au pire cas testé par
  Scrim). »

## Dans `light.tokens.json` et `dark.tokens.json`

`color.media-placeholder` (`--pp-color-media-placeholder`), description « Fond d'un média avant
chargement, quand la couleur dominante n'est pas calculée. » : clair `[0.915, 0.01, 270.7]`,
sombre `[0.3, 0.015, 270.7]`. Placer la clé dans le même ordre dans les deux fichiers.

## Tests

- `source.test.mjs` : le nombre de couleurs par thème passe de 13 à 14 ; rien d'autre ne change.
- `media.test.mjs` (nouveau, même style que `source.test.mjs`, lecture des sources JSON) :
  `media.radius` égal à `radius.surface`, `media.rule` égal à `size.rule` ; budgets entiers
  strictement positifs ; `media.scrim.color` et `media.scrim.text` en OKLCH et dans le gamut
  sRGB (`inSrgbGamut` de `../src/lib/color.mjs`) ; opacité dans ]0, 1[ ; placeholder
  différent de `color.bg` dans chaque thème. Puis vérifier dans `generated/tokens.json` que
  `--pp-media-radius`, `--pp-media-scrim-opacity` et `--pp-color-media-placeholder` existent.

La matrice de contraste (`contrast-matrix.test.mjs`) doit rester verte sans modification.
Fichiers ≤ 120 lignes.
