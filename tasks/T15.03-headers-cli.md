Lis `apps/docs/scripts/headers/*.mjs` (T15.01 et T15.02), `apps/docs/scripts/markdown.mjs`
(modèle de CLI avec FS injecté) et `apps/docs/e2e/serve.mjs` (serveur statique des e2e).
L'orchestrateur ajoute la commande au script `build` ; tu ne touches pas `package.json`.

1. `scripts/headers/run.mjs` : `run({ dist, deploy, list, read, write })` (FS injecté, pur côté
   test) : lit chaque `*.html` de `dist`, agrège `inlineHashes` (union triée), échoue si
   `inlineStyleAttributes` > 0 (message avec le fichier : la CSP stricte ignore `style=""`),
   construit `buildRules`, puis écrit : `dist/_headers` et `dist/_redirects` (Cloudflare Pages ;
   Netlify les lit aussi), et dans `deploy` (défaut `<dist>/../deploy`, hors du dossier servi) :
   `netlify.toml`, `vercel.json`, `nginx.conf`. Retourne la liste des fichiers écrits. Un contrôle
   final relit chaque sortie et vérifie la présence de chaque nom de `REQUIRED_HEADERS` (erreur
   claire sinon). `scripts/headers.mjs` : fine enveloppe CLI (`--dist`, `--deploy`) sous
   `import.meta.main`. Test avec FS en mémoire : sorties écrites, union des hachages, refus d'un
   attribut `style`, en-tête manquant détecté.
2. `e2e/serve.mjs` : si `dist/_headers` existe, applique ses règles aux réponses (analyse du format
   Cloudflare : une règle `/*` et des règles de préfixe `/_astro/*`) ; sinon comportement actuel.
3. `e2e/csp.spec.ts` (projet `chromium`) : pour **chaque page** de `dist` (liste comme
   `helpers.ts`), la réponse porte la CSP et les en-têtes de `REQUIRED_HEADERS` ; aucune
   violation (`securitypolicyviolation` capturé via `page.addInitScript`, et messages console de
   type CSP) ; la page `/recherche/` effectue une recherche (« Dialog ») sans violation, ce qui
   exige `'wasm-unsafe-eval'` ; le mode sombre et le menu mobile s'ouvrent sans violation.
   Importe `REQUIRED_HEADERS` depuis `../scripts/headers/policy.mjs`.

Limites d'`AGENTS.md` : fichiers ≤ 120 lignes (découpe dans `scripts/headers/`), pas de `any`, pas
de `console` (écris sur `process.stdout`), constantes nommées.
