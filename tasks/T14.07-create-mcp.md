gap.md n° 28, mission L14 point 4. Un site généré par `npm create @paulperigault` doit guider une
IA vers le design system : serveur MCP `@paulperigault/mcp` (binaire `pp-mcp`, stdio) et règles.

1. Gabarits de configuration, un par client, même serveur `pp-ds` :
   - `_mcp.json` (Claude Code, `.mcp.json`) : `{ "mcpServers": { "pp-ds": { "command": "npx",
"args": ["--no-install", "pp-mcp"] } } }` ;
   - `_kiro/settings/mcp.json` (Kiro) : même contenu, plus `"disabled": false` ;
   - `_cursor/mcp.json` (Cursor) : même contenu.
     `--no-install` : le paquet est une `devDependency` du site (aucun téléchargement à
     l'exécution). Les segments commençant par `_` deviennent `.` à l'écriture (`outputPath`).
2. `versions.json` : ajoute `"@paulperigault/mcp": "0.0.0"` (ordre alphabétique conservé) ;
   `package-json.mjs` : ajoute `@paulperigault/mcp` aux `DEV_DEPENDENCIES`.
3. `AGENTS.md` du site généré, en français, court (≤ 60 lignes), sans formule creuse : le site
   utilise le design system @paulperigault ; règles pour une IA : (a) interroger le MCP `pp-ds`
   avant d'écrire un composant (`list_components`, `get_component`, `get_tokens`,
   `validate_snippet`) ; (b) utiliser les composants existants, ne pas en inventer ; (c) styler
   par les jetons `--pp-*` seulement ; (d) aucun attribut `style` en ligne (CSP stricte) ;
   (e) propriétés logiques ; (f) lancer `npm run verify` avant de conclure ; (g) interdits
   (dégradés décoratifs, ombres décoratives, flou, emoji, palette Tailwind par défaut,
   valeurs arbitraires) sans citer les motifs en toutes lettres qui ferait échouer
   `pp-guards design` : le fichier est lui-même contrôlé (commande d'acceptation) ; si une
   formulation est refusée par le garde-fou, reformule-la sans la contourner.
4. `README.md` du site : une section « Assistants IA » (trois lignes) qui renvoie à `AGENTS.md`
   et aux trois fichiers de configuration.
5. Tests : l'instantané des chemins et empreintes est mis à jour (`vitest -u` pour ce seul
   fichier de test, puis relis le diff : seuls les nouveaux fichiers et `package.json` changent) ;
   ajoute des assertions explicites : les trois configurations existent, parsent en JSON valide,
   désignent `pp-mcp`, et `package.json` du site déclare `@paulperigault/mcp` en `devDependencies`.

Fichiers ≤ 120 lignes, pas de `any`, pas de `console`.
