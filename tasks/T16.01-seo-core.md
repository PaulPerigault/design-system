Mission « site vitrine d'auteur » (P4). Auteur unique : **Paul Périgault** (DevOps / DevSecOps),
portfolio https://paulperigault.fr (le site vitrine et le portfolio se renforcent : liens,
`sameAs`, canonicals cohérents). Le favicon n'est jamais touché. Lis `DocsLayout.astro`,
`ComponentPage.astro`, `lib/component-page.ts` et `navigation.ts` d'abord.

1. `lib/site.ts` : constantes (`SITE_URL = 'https://design.paulperigault.dev'`, nom du site « Design
   system @paulperigault », `AUTHOR = { name: 'Paul Périgault', url: 'https://paulperigault.fr',
github: 'https://github.com/PaulPerigault', jobTitle: 'DevOps / DevSecOps' }`, langue `fr`).
2. `lib/seo.ts` (pur, testé) : `titleOf(page)`, `canonicalOf(pathname)` (toujours avec barre finale,
   sans paramètre), et des constructeurs JSON-LD **valides schema.org** : `personLd()` (`Person` :
   `name`, `url` = portfolio, `sameAs` = [portfolio, GitHub], `jobTitle`), `websiteLd()`
   (`WebSite`, `author` = Person, `inLanguage`), `softwareLd()` (`SoftwareSourceCode` : dépôt
   GitHub, licence MIT `https://opensource.org/licenses/MIT`, `programmingLanguage`),
   `techArticleLd({ title, description, url })` (`TechArticle`, `author`, `inLanguage`),
   `breadcrumbLd(items)` (`BreadcrumbList`, `ListItem` avec `position`, `name`, `item` absolu),
   `graph(...nodes)` (`@context` une seule fois, `@graph`). Tests : champs obligatoires,
   URL absolues, pas de `undefined`, positions consécutives.
3. `components/SeoHead.astro` : dans `<head>` : `<meta name="description">`, `<link rel="canonical">`,
   `<link rel="author" href=portfolio>`, `<meta name="author">`, Open Graph (`og:type`,
   `og:title`, `og:description`, `og:url`, `og:locale` `fr_FR`, `og:site_name`, `og:image` =
   `${SITE_URL}/og/<slug>.png` (l'image est produite par une autre tâche), `og:image:width`
   1200, `og:image:height` 630, `og:image:alt`), `twitter:card` `summary_large_image`, et un
   `<script type="application/ld+json">` par graphe (sérialisé avec `JSON.stringify`, `<`
   échappé en `\u003c`). Aucun attribut `style`, aucune ressource tierce.
4. `DocsLayout.astro` : nouvelles propriétés `description` (obligatoire) et `jsonLd?` (graphe
   supplémentaire) ; inclut `SeoHead` ; ajoute un lien visible « Paul Périgault » avec
   `rel="author"` vers le portfolio dans le pied de page (conserve le texte actuel ; ne
   modifie pas la navigation : l'orchestrateur la possède). Le `<title>` garde le format
   `Titre · Design system · Paul Perigault`.
5. `ComponentPage.astro` : `description` = `summary` ; JSON-LD `TechArticle` + `BreadcrumbList`
   (Accueil › Composants › groupe › composant).
6. Pages existantes (`index`, `identite`, `accessibilite`, `glossaire`, `recherche`) : ajoute une
   `description` **unique** de 120 à 160 caractères, factuelle (ce que la page contient, en
   français, sans formule creuse). `index` porte en plus `jsonLd` = Person + WebSite.
7. `pages/sitemap.xml.ts` (endpoint statique) : toutes les pages construites (`import.meta.glob`
   des pages `.astro`, sauf les endpoints), URL canoniques, `lastmod` absent (pas de date
   inventée). `pages/robots.txt.ts` : `User-agent: *`, `Allow: /`, `Sitemap: <URL>`.
8. `e2e/seo.spec.ts` : pour chaque page de `dist` (liste de `helpers.ts`) : un seul `<h1>`,
   `<title>` unique sur tout le site, `description` unique de 50 à 170 caractères, canonical
   absolu terminé par `/`, JSON-LD qui parse et dont chaque `@type` est connu, `og:image`
   présent ; `/sitemap.xml` liste chaque page ; `/robots.txt` référence le sitemap.

Limites d'`AGENTS.md` : fichiers ≤ 120 lignes (découpe), pas de `any`, jetons `--pp-*`, français.
