Générateur maison, sans dépendance, du sous-ensemble DTCG utilisé (`color` oklch, `dimension`,
`duration`, `fontFamily`, `fontWeight`, `number`, `cubicBezier`). Il lit
`packages/tokens/src/tokens/resolver.json` et ses fichiers, et écrit `packages/tokens/generated/`
(fichiers versionnés). `node scripts/build.mjs --check` régénère en mémoire et **échoue** (code 1,
liste des fichiers) si un fichier versionné diffère : un token modifié sans régénération casse la CI.

## Sorties

- `tokens.css` : en-tête « fichier généré, ne pas éditer » ;
  `:root { color-scheme: light dark; … }` avec chaque couleur en
  `--pp-color-<chemin>: light-dark(<clair>, <sombre>);` (valeurs `oklch(L% C H)` via `formatOklch`
  de `../src/lib/color.mjs`) et chaque token de base (`--pp-space-m: 1.5rem;`,
  `--pp-font-family-sans: "Atkinson Hyperlegible Next Variable", "Atkinson Next Fallback", system-ui, sans-serif;`,
  `--pp-duration-base: 160ms;`, `--pp-easing-standard: cubic-bezier(0.2, 0, 0, 1);`, …) ;
  puis `:root[data-theme='light'] { color-scheme: light; }`, `:root[data-theme='dark'] { color-scheme: dark; }`,
  et `@media (prefers-reduced-motion: reduce) { :root { --pp-duration-fast: 0ms; --pp-duration-base: 0ms; } }`.
  Nom d'une variable : `--pp-` + chemin joint par `-` (`color.status.passed` → `--pp-color-status-passed`,
  `font.size.-1` → `--pp-font-size--1`).
- `tokens.json` : `{ "themes": { "light": { "<nom>": { "oklch": "…", "hex": "#…" } }, "dark": {…} },
"base": { "<nom>": "<valeur CSS>" }, "themeColor": { "light": "#…", "dark": "#…" } }`
  (`themeColor` = `color.bg` de chaque thème, pour `<meta name="theme-color">`).
- `tokens.d.ts` : `export type TokenName = '--pp-…' | …;` (tous les noms, triés) et
  `export declare const themeColor: { readonly light: '#…'; readonly dark: '#…' };`.

Sorties déterministes (tri des clés, saut de ligne final), lisibles par Prettier.

## Tests `build.test.mjs`

Sur une source minimale en mémoire (lecteur injecté) : aplatissement, valeurs CSS par type,
`light-dark()`, noms de variables, `--check` qui détecte une dérive ; et sur la vraie source :
`themeColor.dark` vaut `#14161c`, toutes les couleurs sont dans le gamut (sinon `toHex` lève).
