Point d'entrée unique `pp-guards <contrôle> [options] [racines…]` de `@paulperigault/guards`.
Lis d'abord `src/lib/*.mjs`, `src/check-design.mjs`, `src/check-size.mjs`, `src/check-layers.mjs`,
`src/check-images.mjs` (contrat : `name`, `defaults`, `cliOptions`, `run(options, io)`) et
`src/check-tokens.mjs`, qu'il ne faut **pas modifier** (`run(argv, io)` avec
`io = { readFile, readdirSync, out, err }`).

## `src/checks.mjs`

Table des contrôles : `design`, `size`, `layers`, `images`, et `tokens` par un adaptateur qui
appelle `check-tokens` `run(argv, io)` : drapeaux et positionnels transmis tels quels ; en
configuration, `{ "tokens": "<tokens.json>", "roots": [...] }` reconstruit
`['--tokens', tokens, ...roots]` ; `readFile` ← `readText`, `readdirSync` ← `readdir`.

## `src/config.mjs`

- `loadConfig(io, path)` : `path` explicite (`--config`) absent → `GuardUsageError` ; sans
  `--config`, `pp-guards.config.json` du dossier courant s'il existe, sinon `{}`. JSON invalide →
  `GuardUsageError` avec le chemin.
- `mergeOptions(defaults, section, flags, positionals)` : défauts ← section du fichier ←
  drapeaux ; un tableau remplace, il ne s'ajoute pas ; positionnels non vides → `roots`. Pure.

## `src/cli.mjs`

- `main(argv, io)` → code : `node:util` `parseArgs` en mode strict avec les `cliOptions` du
  contrôle + `--config <fichier>` + `--help`. Contrôle inconnu, option inconnue ou absente →
  usage sur `io.err`, code `2`. `GuardUsageError` → message, code `2`.
- `pp-guards all` : lance, dans l'ordre `tokens`, `design`, `size`, `layers`, `images`, chaque
  contrôle qui a une section dans la configuration (aucune section → code `2`) ; code = le plus
  élevé.
- `pp-guards --help` et `pp-guards <contrôle> --help` : usage sur `io.out`, code `0`.

## `bin/pp-guards.mjs`

Shebang `#!/usr/bin/env node`, `process.exitCode = main(process.argv.slice(2), nodeIo(process))`.
Rien d'autre : toute la logique est dans `src/`, testée sans disque avec `test/fake-io.mjs`.

## Critères

- Tests : dispatch de chaque contrôle, fusion des options (priorité, tableaux remplacés),
  configuration implicite et explicite, `all`, `tokens` par drapeaux et par configuration, codes
  0/1/2.
- Les commandes d'acceptation `node packages/guards/bin/pp-guards.mjs …` passent sur le dépôt.
