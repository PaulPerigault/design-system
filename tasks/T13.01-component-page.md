Contexte : `docs/benchmark/gap.md` lignes 21 et 22 (L13). Les pages de composant de
`apps/docs/src/pages/components/*.astro` sont libres ; le gabarit les rend uniformes (GOV.UK,
Primer). Modèle de page : `button.astro`. Tableau de propriétés : `components/PropsTable.astro`.
Registre : `@paulperigault/astro/registry.json` (champ `meta.tokens` de chaque élément).

Crée `components/ComponentPage.astro`, qui enveloppe `DocsLayout` (titre de l'onglet
`<title> · Design system · Paul Perigault`, comme aujourd'hui) et rend **toujours dans cet ordre**
(chaque `<h2>` a l'id indiqué) :

1. `<h1>` = `title`, puis `summary` (une phrase) : `#sert` (h2 « À quoi il sert » avec la phrase) ;
2. `#quand` « Quand l'utiliser » : liste `use` ; puis `#eviter` « Quand ne pas l'utiliser » :
   liste `avoid` (les deux listes gardent leurs puces, pas de `list-style: none`) ;
3. `#exemples` « Exemples » : slot par défaut, puis le code copiable `snippet` dans
   `<pre tabindex="0"><code>` (focalisable pour défiler au clavier, 2.1.1) ;
4. `#variantes` « Variantes » : slot nommé `variants` (section omise si le slot est vide) ;
5. `#accessibilite` « Accessibilité » avec quatre `<h3>` : « Clavier », « Lecteur d'écran »,
   « Garanti par le composant », « À la charge de l'intégrateur » (listes de `a11y`) ;
6. `#proprietes` « Propriétés » : `<PropsTable item={slug} title={title} />` ;
7. `#jetons` « Jetons utilisés » : les `meta.tokens` du registre, une `<code>` par jeton, dans
   une liste ;
8. `#preuves` « Preuves et décisions » : liste `evidence` (`label`, `href` optionnel).

Types et validation dans `lib/component-page.ts` (pur, testé) : interface `ComponentPageData`
(`slug`, `title`, `summary`, `use`, `avoid`, `snippet`, `a11y: { keyboard, screenReader,
guaranteed, integrator }`, `evidence`), constante `SECTIONS` (ids et titres, source unique de
l'ordre, réutilisée par le sommaire de page) et `validate(data)` qui lève une erreur claire si un
champ obligatoire est vide (`use`, `avoid`, `summary`, quatre listes d'accessibilité,
`evidence`). Le test couvre l'ordre de `SECTIONS` et chaque refus.

Style dans `styles/component-page.css` (jetons `--pp-*` seulement, propriétés logiques, aucune
valeur brute, aucun attribut `style`). Marge au-dessus des `h2` pour scinder les sections.

Migre `pages/components/separator.astro` vers le gabarit (contenu fidèle à la page actuelle,
en lisant `packages/astro/src/**/Separator.astro` pour les garanties d'accessibilité ; ne cite
que ce qui est vrai dans le code). Elle sert de modèle aux autres migrations.
