`check-images` (`packages/guards/src/check-images.mjs`, `src/images/*.mjs`, T8.04) est intégré
et approuvé ; deux revues ont laissé les remarques suivantes, à traiter. Ne change pas le contrat
du module (`name`, `defaults`, `cliOptions`, `run`) ni les messages existants. Si un test dépasse
120 lignes, déplace les cas de balisage vers `test/image-markup.test.mjs`.

1. `markup.mjs` : la neutralisation de `/* … */` s'applique aussi dans les chaînes ; un
   `'/src/*'` dans le frontmatter d'un `.astro` ouvre un faux commentaire qui masque les `<img`
   suivants (faux négatif). Ne neutraliser `/* */` que dans les `.css` et les blocs `<style>` (et
   `{/* */}` des `.jsx`/`.tsx`/`.mdx`) ; `<!-- -->` partout. Test du cas `'/src/*'` puis `<img`.
2. `png.mjs` : un chunk `eXIf` doit aussi rendre `gps` quand son bloc TIFF porte GPSInfo
   (réutiliser `tiffHasGps` de `jpeg.mjs`). Test avec un `eXIf` `II` à GPS et un sans GPS.
3. `jpeg.mjs` : constante `BYTE_ORDER_SIZE = 2` pour l'ordre TIFF (`II`/`MM`) au lieu de
   réutiliser `MARKER_SIZE`.
4. Tests : extensions insensibles à la casse (`public/ME.JPG` à GPS signalé, `src/A.Astro` avec
   `<img`) ; `<img` refusé dans chacune des six extensions de balisage (`.astro`, `.html`, `.md`,
   `.mdx`, `.jsx`, `.tsx`).
