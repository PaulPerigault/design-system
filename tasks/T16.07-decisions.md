Rends les ADR de `docs/adr/*.md` (ADR-0001 à ADR-0004) comme pages. `lib/adr.ts` (pur, testé) :
`adrId(filename)` (`0003-mcp.md` → `0003`), `adrTitle(markdown)` (première ligne `# ADR-… — …`),
`adrStatus(markdown)` (ligne `- Statut : …`), `summary(markdown)` (premier paragraphe du
contexte, ≤ 200 caractères). `pages/decisions/[id].astro` : `getStaticPaths` via
`import.meta.glob('../../../../../docs/adr/*.md', { eager: true })` (le chemin relatif part de
`apps/docs/src/pages/decisions/`, vérifie-le), rend `<Content />` d'Astro dans `DocsLayout`
(titre `ADR-0003 … · Design system · Paul Perigault`, description = `summary`), JSON-LD
`TechArticle` (importe `techArticleLd` de `../../lib/seo` si présent, sinon omets-le), lien
de retour `/decisions/`. `pages/decisions/index.astro` : liste des ADR (identifiant, titre,
statut, résumé) et rappel que le journal des décisions (`docs/decisions-log.md`) détaille les
choix ouverts (D-001…) : pas de rendu des 25 lignes ici, lien vers le dépôt GitHub
`https://github.com/PaulPerigault/design-system/blob/develop/docs/decisions-log.md`. Les
tableaux Markdown des ADR doivent rester lisibles à 320 px (conteneur défilant focalisable :
`overflow: auto` + `tabindex="0"` n'est pas posable sur le contenu rendu → entoure `<Content />`
d'un `div` à `overflow-inline: auto` n'est pas valide ; utilise `max-inline-size: 100%` et
`overflow-wrap: anywhere` dans un style `:global()` sous une classe racine, et teste à 320 px).

Règles de contenu (AGENTS.md) : français simple, phrases de 25 mots au plus, un terme par notion,
aucune formule creuse (« passionné par », « solutions innovantes »…). « Prouvé » seulement si une
source l'établit (norme, auteur, année) ; sinon « convention » ou « préférence ». N'écris que des
faits que tu lis dans le dépôt (cite le fichier ou le test qui les établit en texte) ; **n'invente
aucun chiffre, aucune date, aucun employeur, aucune formation**. Les passages à la première
personne ou parlant de Paul sont des brouillons : insère `<DraftNotice />`
(`../components/DraftNotice.astro`) en tête de page. Chaque page passe à `DocsLayout` un `title`
(format `Titre · Design system · Paul Perigault`) et une `description` unique de 120 à 160
caractères. Pas de nouveau composant ni de CSS brut : réutilise `@paulperigault/astro`
(`Alert`, `Table`, `Stack`, `Cluster`, `Prose`…, lis leurs `Props`) et les jetons `--pp-*`.
Propriétés logiques, aucun attribut `style`, cibles ≥ `--pp-size-target-min`. Fichiers ≤ 120 lignes.
Acceptation : formatage, `astro check`, build, taille ; le test e2e SEO (`seo.spec.ts`) devra
passer sur la page (un seul `<h1>`, titre et description uniques).
