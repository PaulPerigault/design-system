Contrôle des interdits « anti-IA » d'`AGENTS.md` pour les sites consommateurs et le dépôt. Lis
`AGENTS.md` (section « Interdits ») et le socle `packages/guards/src/lib/*.mjs` (T8.01) : utilise
`listFiles`, `matchesAny`, `lineOf`, `report`, et `test/fake-io.mjs` pour les tests.

export const name = 'design';
export const defaults = { roots: ['src'], extensions: [...], allow: [], disable: [] };

## Règles (identifiant stable, message en français avec la règle et l'extrait fautif)

- `gradient` : `linear-`, `radial-`, `conic-gradient(` et `repeating-*` ; classes
  `bg-gradient-*`, `bg-linear-*`, `bg-radial*`, `bg-conic*`.
- `shadow` : `box-shadow` / `text-shadow` dont la valeur n'est pas `none` ; `drop-shadow(` ;
  classes `shadow*`, `drop-shadow*` sauf `shadow-none`.
- `blur` : `backdrop-filter`, `blur(` ; classes `blur*`, `backdrop-*`.
- `emoji` : `\p{Emoji_Presentation}` ou `\p{Extended_Pictographic}\uFE0F` (©, ®, ™, ↔, →
  restent permis).
- `spaced-caps` : même bloc CSS avec `text-transform: uppercase` **et** `letter-spacing`
  positif ; même attribut `class` avec `uppercase` **et** `tracking-wide`, `-wider`, `-widest` ou
  une valeur positive.
- `tailwind-palette` : classes `<utilitaire>-<teinte>-<50…950>` des teintes par défaut (slate,
  gray, zinc, neutral, stone, red… rose) ; `var(--color-<teinte>-<n>)`.
- `arbitrary-value` : classes à valeur arbitraire `p-[13px]`, `bg-[#fff]`, `w-[calc(…)]` (pas
  les sélecteurs d'attribut CSS `.x[data-y]`).
- `color-literal` : dans les valeurs CSS, hex `#rgb(a)`/`#rrggbb(aa)`, `rgb(a)(`, `hsl(a)(`,
  `hwb(`, `lab(`, `lch(`, `oklab(`, `oklch(`, `color(` ; couleurs nommées CSS
  (`named-colors.mjs`) dans les propriétés de couleur. Permis : `var(--…)`, `currentColor`,
  `transparent`, `inherit`, `initial`, `unset`, `none`. Les sélecteurs `#id` ne sont pas des
  couleurs.
- `retro-effect` : noms d'animation ou de `@keyframes` contenant `glitch`, `typewriter`,
  `typing`, `scanline`, `blink-caret`.
- `generic-phrase` : phrases génériques, insensibles à la casse. FR « passionné(e) par »,
  « solutions innovantes », « à la pointe de », « dans un monde en constante évolution »,
  « n'hésitez pas à », « synergie » ; EN « passionate about », « innovative solutions »,
  « cutting-edge », « seamless », « game-changer », « best-in-class », « in today's fast-paced ».

- La police **mono est permise** (ADR-0002) : aucune règle ne vise `font-mono`, `monospace` ou
  `--pp-font-mono` ; un test le prouve.
- Portée : règles CSS dans `.css` et les blocs `<style>` / attributs `class`/`class:list` des
  `.astro`, `.html`, `.jsx`, `.tsx` ; `emoji` et `generic-phrase` aussi dans `.md`, `.mdx`.
  Défaut `extensions` : `.astro`, `.css`, `.html`, `.md`, `.mdx`, `.jsx`, `.tsx`.
- Les commentaires `/* … */` et `<!-- … -->` sont neutralisés (remplacés par des espaces, sauts de
  ligne conservés) avant analyse : les numéros de ligne restent justes.

## Configuration

- `allow` : liste blanche de chemins (règle de `matchesPath`). Une entrée est une chaîne (toutes
  les règles) ou `{ "path": "…", "rules": ["shadow"], "reason": "ADR-00xx" }` (règles citées).
- `disable` : identifiants de règles coupées partout.
- Identifiant inconnu dans `rules` ou `disable` → `GuardUsageError`.

## Critères

- Au moins un cas refusé et un cas permis par règle, plus les faux positifs connus : `#main {`,
  `.x[data-space='m']`, `letter-spacing: -0.01em` avec `uppercase`, `transition: box-shadow`
  (propriété citée, pas d'ombre), `shadow-none`, l'emoji dans un commentaire CSS.
- `fichier:ligne` exact pour chaque problème ; tests sans disque.
- Données (listes de teintes, couleurs nommées, phrases) dans des fichiers séparés : ≤ 120 lignes
  par fichier ; tableaux de chaînes plutôt que de nombres (aucun nombre magique hors tests).
