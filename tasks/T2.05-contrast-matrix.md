Contraste WCAG 2.2 **bloquant**, généré depuis une matrice de rôles, dans les deux thèmes, calculé
sur la couleur sRGB rendue (`contrastRatio` de `../src/lib/contrast.mjs`, source DTCG lue
directement dans `src/tokens/*.tokens.json`, pas dans un CSS généré).

`roles.json` : `{ "pairs": [ { "fg": "color.fg", "bg": "color.bg", "min": 7, "norm": "WCAG 1.4.6 (AAA, texte)" }, … ] }` avec :

- 7 : `color.fg` sur `color.bg` et sur `color.surface` ;
- 4,5 : `color.muted` sur `color.bg` et `color.surface` ; `color.accent` sur `color.bg` et
  `color.surface` ; `color.on-accent` sur `color.accent` ; chaque `color.status.*` sur `color.bg`
  et `color.surface` ;
- 3 : `color.control` sur `color.bg` et `color.surface` ; `color.focus` sur `color.bg` et
  `color.surface` (WCAG 1.4.11 et 2.4.13).

Le test parcourt `roles.json` × `["light", "dark"]` (un `it.each` par paire et par thème, nom
lisible : `dark : color.muted sur color.surface ≥ 4.5`), et vérifie aussi que chaque rôle de la
matrice existe dans les deux thèmes. Il **ne relâche jamais** un seuil : si une paire échoue, le
test échoue.
