Deux commandes de `@paulperigault/create` (kickoff §1.2 : import par défaut, `eject` par
exception). Lis le socle `packages/create/src/lib/*.mjs` et `test/fake-io.mjs` (T8.08) et
`packages/astro/registry/items/stack.json`, `packages/astro/package.json` (`exports`).

## Contrat de commande (commun)

`export function run({ positionals, dryRun, force, from, out }, ctx)` → code (`0` succès, `1`
refus, `2` usage) ; `ctx = { io }`. Un positionnel exactement : le nom de l'élément (sinon `2`).
Toute écriture passe par `applyPlan` (`--dry-run` liste sans écrire, conflits sans `--force` =
refus atomique). Erreurs du registre (paquet absent, élément inconnu) → message sur `io.err`,
code `2`.

## `add <élément>` (mode par défaut : import du paquet)

- Élément cherché dans le registre du paquet installé (`packageRoot(io, from)`, `findItem`).
- Si `package.json` du projet n'a `@paulperigault/astro` ni en `dependencies` ni en
  `devDependencies`, l'ajoute en `dependencies` à la version **exacte** installée
  (`packageVersion`), indentation et clés existantes conservées, entrée de plan
  `overwrite: true`. Sans `package.json` → code `1`.
- Affiche l'extrait d'import par fichier `.astro` de l'élément :
  `import Stack from '@paulperigault/astro/Stack.astro';` (`snippet.mjs`, partagé avec `eject`).
  Si l'export `./Stack.astro` manque dans les `exports` du paquet installé, avertissement explicite
  sur `io.err` (code inchangé).
- Affiche les `registryDependencies` de l'élément s'il en a.

## `eject <élément>` (exception : copie dans le projet)

- Copie chaque fichier de `itemFiles(item)` du paquet vers `<out>/<chemin sans le préfixe src/>`,
  `out` par défaut `src/components/pp` (`src/layout/Stack.astro` →
  `src/components/pp/layout/Stack.astro`).
- Inscrit l'élément dans `pp-ds.lock.json` (`readLock`, `withItem`, `serializeLock`) :
  `package`, `version` installée, et par fichier `source`, `path`, `sha256` du contenu copié.
  Entrée du verrou `overwrite: true` ; les fichiers copiés, non.
- Fichier cible existant ou élément déjà au verrou → refus sans `--force` (tous les conflits
  listés, rien d'écrit, code `1`).
- Affiche ensuite l'import de la copie (`import Stack from './components/pp/layout/Stack.astro';`
  relatif à `src/`) et rappelle que `diff <élément>` compare la copie au paquet.

## Critères

Tests sans disque (`fakeIo` + `fakePackage`) : ajout de dépendance et non-ajout si présente,
extrait d'import, export manquant, élément inconnu, `eject` (fichiers, verrou, empreintes),
`--out`, refus d'écraser puis `--force`, `--dry-run` sans écriture pour les deux commandes,
second `eject` d'un autre élément qui conserve le premier au verrou.
