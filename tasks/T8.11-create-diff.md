`diff <élément>` de `@paulperigault/create` : compare la copie éjectée d'un élément au paquet
`@paulperigault/astro` installé. Lis le socle `packages/create/src/lib/*.mjs` (format du verrou
`pp-ds.lock.json` dans `lock.mjs`) et `test/fake-io.mjs` (T8.08). Lecture seule : aucune écriture.

## Contrat de commande (commun)

`export function run({ positionals, dryRun, force, from, out }, ctx)` → code ; `ctx = { io }`.
Un positionnel exactement (sinon `2`).

## Comportement

- Élément absent du verrou → `io.err` « élément non éjecté : eject <élément> d'abord », code `2`.
- Côté copie : les fichiers du verrou (`path`), lus dans le projet. Côté paquet : `itemFiles` de
  l'élément dans le registre installé (`packageRoot(io, from)`), reliés à la copie par `source`.
- Classement par fichier (`source`), en sortie triée :
  - `modifié` : présent des deux côtés, contenus différents ; précise `local` si l'empreinte de la
    copie diffère de celle du verrou, `paquet` si celle du paquet en diffère, `local, paquet` si
    les deux ;
  - `ajouté` : présent dans le paquet, absent de la copie (nouveau fichier en amont, ou copie
    supprimée) ;
  - `supprimé` : présent dans la copie (au verrou), absent du paquet.
- En-tête : `<élément> : copie <version du verrou>, paquet <version installée>`.
- Code `0` si tout est identique (`<élément> : identique au paquet`), `1` s'il y a au moins une
  différence.

## Critères

Tests sans disque (`fakeIo` + `fakePackage`, verrou écrit à la main avec `sha256`) : identique,
modifié local, modifié paquet, les deux, ajouté, supprimé, versions différentes, non éjecté.
