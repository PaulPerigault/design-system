Deux contrôles de `@paulperigault/guards`, bâtis sur le socle `packages/guards/src/lib/*.mjs`
(T8.01 : `listFiles`, `matchesPath`, `report`, `GuardUsageError`, `test/fake-io.mjs`).

## Contrat de module (identique pour chaque contrôle)

`export const name`, `export const defaults`, `export const cliOptions` (descripteurs
`node:util` `parseArgs`), `export function run(options, io)` → `0` | `1` (via `report`).
`options` arrive fusionné (défauts ← fichier de configuration ← drapeaux) par la CLI (T8.06) ;
`options.roots` reçoit les positionnels.

## `check-size` (`name = 'size'`)

- Défauts : `max: 120`, `extensions: ['.ts', '.astro', '.css', '.mjs']`, `roots: ['src']`.
- Problème : `fichier: <n> lignes (max <max>)`. Comptage identique à
  `tools/checks/check-size.mjs` (`countLines` : un saut de ligne final ne compte pas) ; lis-le, ne le
  modifie pas.
- Drapeaux : `--max <n>`, `--ext <.x>` (multiple). `max` non entier positif → `GuardUsageError`.

## `check-layers` (`name = 'layers'`)

- Configuration : `layers` = liste **ordonnée de la plus basse à la plus haute**, chaque couche
  `{ name, paths: string[], packages?: string[] }`, plus `roots` et `extensions` (défauts
  `['.ts', '.mjs', '.js', '.astro', '.css']`). Exemple du dépôt : `tokens` ← `css` ← `astro`
  (`astro` peut importer `css` et `tokens` ; `tokens` n'importe ni `css` ni `astro`).
- `src/layers/imports.mjs` : `importsOf(text)` → `[{ specifier, line }]` pour `import … from 'x'`,
  `import 'x'`, `export … from 'x'`, `import('x')` littéral, `import type … from 'x'`, CSS
  `@import 'x'` / `@import url(x)` ; dans un `.astro`, le frontmatter et les `<script>`.
- Résolution d'une cible : spécificateur relatif → chemin normalisé depuis le dossier du fichier,
  couche dont un `paths` est un préfixe de segments ; nom de paquet (`@scope/nom/sous-chemin` →
  `@scope/nom`, `nom/x` → `nom`) → couche qui le liste dans `packages`. Le reste est ignoré.
- Problème : un fichier d'une couche `i` importe une cible d'une couche `j > i` :
  `fichier:ligne: la couche « tokens » importe « css » (<spécificateur>), sens refusé`.
- **Échec** si aucun fichier parcouru n'appartient à une couche (configuration erronée) :
  problème unique `aucun fichier n'appartient à une couche : vérifier layers[].paths`.
- `layers` absent, vide, nom en double ou couche sans `paths` → `GuardUsageError`.

## Critères

- Tests sans disque, avec un arbre factice de trois couches : import permis (vers le bas), refusé
  (vers le haut, relatif et par nom de paquet), import d'un fichier hors couche ignoré, cas
  « aucun fichier », chaque forme d'import, numéros de ligne.
- Fichier ≤ 120 lignes, fonction ≤ 40, complexité ≤ 8, aucun nombre magique ; `no-undef` actif
  (importe les globaux Node depuis `node:*`).
