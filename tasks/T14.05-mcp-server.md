## Outils (noms exacts, un fichier de schémas `schemas.mjs`)

- `list_components` : `{ group?: string }` → liste `{ slug, title, summary }`.
- `get_component` : `{ slug }` → rôle (summary), quand l'utiliser / ne pas l'utiliser, propriétés,
  exemple (snippet), garanties d'accessibilité (quatre listes), jetons, preuves. Slug inconnu :
  erreur avec les slugs proches.
- `get_tokens` : `{ role?: string, theme?: 'light'|'dark' }` → jetons `--pp-*` par rôle et par
  thème avec valeur (OKLCH et sRGB hex rendu) et, pour les paires avant/arrière-plan connues,
  le contraste WCAG calculé.
- `check_contrast` : `{ foreground, background }` où chaque valeur est une couleur CSS
  (`#rgb`, `#rrggbb`, `oklch(...)`) **ou** un jeton `--pp-…` (avec `theme`) → ratio WCAG 2
  (via `@paulperigault/tokens/contrast`), niveaux AA/AAA texte normal et grand texte, et
  **APCA (Lc) à titre informatif** : implémente APCA-W3 0.1.9 dans `apca.mjs` (constantes de la
  spécification officielle, vérifie-les sur la source primaire : https://github.com/Myndex/apca-w3 ;
  note dans le résultat que APCA est informatif et non normatif en WCAG 2.2).
- `validate_snippet` : `{ language: 'astro'|'html'|'css'|'md', code }` → violations des garde-fous
  (`@paulperigault/guards` : règles de `design/rules.mjs` via `analyze`, tokens `--pp-*`
  inconnus, `style` en ligne, images sans dimensions) avec identifiant de règle, ligne, message
  et **correction proposée**. Expose `analyze` en ajoutant `"./design": "./src/design/rules.mjs"`
  aux `exports` de `packages/guards/package.json` (seul changement permis dans ce fichier) ;
  passe le code **en mémoire** (jamais d'écriture de fichier temporaire).
- `search_docs` : `{ query, limit? ≤ 20 }` → recherche plein texte simple (normalisation
  d'accents, minuscules, score par occurrences dans titre et corps) dans `docs.json`.
- `get_decision` : `{ id }` (`ADR-0002`, `D-021`…) ou `{ query }` → texte de l'ADR ou de la ligne
  du journal des décisions.

Chaque outil porte `title`, `description` en français, et les annotations MCP
`readOnlyHint: true`, `destructiveHint: false`, `openWorldHint: false`.

## Serveur et binaire

`src/server.mjs` : `createServer(deps)` assemble les outils (dépendances injectées : données,
analyse) ; `bin/pp-mcp.mjs` : transport stdio ; **aucune sortie sur stdout hors protocole**
(journaux sur stderr, jamais de `console.log`) ; `--self-test` charge les données, appelle
chaque outil avec un exemple valide via un transport en mémoire du SDK, affiche « ok » sur
stderr et sort avec 0.
