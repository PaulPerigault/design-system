gap.md n° 25. Lis `components/ComponentPage.astro`, `lib/component-page.ts` (`SECTIONS`),
`navigation.ts` (`GROUPS`, `hrefOf`) et le composant `Breadcrumb` de `@paulperigault/astro`
(`packages/astro/src/**/Breadcrumb.astro`, lis ses propriétés).

1. `lib/neighbors.ts` (pur, testé) : `neighborsOf(slug)` renvoie `{ group, previous, next }` selon
   l'ordre aplati de `GROUPS` (précédent/suivant `undefined` aux extrémités, erreur claire si le
   slug est inconnu) ; test : premier, dernier, milieu, changement de groupe, slug inconnu.
2. `components/PageNav.astro` : trois blocs rendus autour du contenu de `ComponentPage` :
   - fil d'Ariane (Accueil › Composants › groupe › composant) avec `Breadcrumb`, nommé
     (`aria-label="Fil d'Ariane"`), dernier élément `aria-current="page"` ;
   - sommaire de page : `<nav aria-label="Sur cette page">` avec une liste de liens vers les
     ancres de `SECTIONS` réellement présentes (prop `sections`), `role="list"` ;
   - précédent / suivant : `<nav aria-label="Pages voisines">`, deux liens, cible ≥ `--pp-size-target-min`.
3. `ComponentPage.astro` : inclut `PageNav` (fil d'Ariane en tête, sommaire après le `<h1>`,
   précédent/suivant en pied) ; la section `variantes` n'apparaît au sommaire que si elle est rendue.
4. `styles/page-nav.css` : jetons `--pp-*` seulement, propriétés logiques, mobile d'abord, zéro JS,
   aucun attribut `style`. Trois repères `nav` portent chacun un nom distinct.

Contraintes : chaque fichier ≤ 120 lignes (découpe si besoin), pas de `any`, français.
