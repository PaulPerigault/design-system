## Select

`<select>` natif. Props : `id`, `name`, `options: { value: string; label: string; disabled?: boolean }[]`,
`value?` (option sélectionnée), `placeholder?` (première option `value=""`, `disabled` et
sélectionnée si `value` absent, avec `required`), `required?`, `disabled?`, `describedBy?`,
`invalid?`. Chevron : SVG inline décoratif (`aria-hidden`, `focusable="false"`) positionné dans
un conteneur, **jamais** de `background-image` ni de dégradé ; `appearance: none` sur le select
avec marge pour le chevron ; contraste du chevron ≥ 3:1 (`--pp-color-control` ou `--pp-color-fg`).
Option sélectionnée marquée par l'attribut `selected`.

Test `packages/astro/test/Select.test.ts` (`renderDom` de `./render`) : rôles et noms accessibles,
attributs ARIA selon les props, valeurs par défaut, aucun attribut `style`. Page de doc
`apps/docs/src/pages/components/select.astro` sur `../../layouts/DocsLayout.astro` : exemples
(défaut, erreur, désactivé), tableau des props, une phrase factuelle d'usage.
