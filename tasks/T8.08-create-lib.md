Socle de la CLI `@paulperigault/create` (commandes `create`, `add`, `eject`, `diff`, écrites
ensuite en parallèle sur ce socle). Fichiers `.mjs`, JSDoc, aucune dépendance d'exécution
(seulement `node:*`). Tout est **synchrone** et passe par un `io` injecté.

## `src/lib/io.mjs`

Typedef JSDoc `CreateIo` et `nodeIo({ cwd, stdout, stderr })` (implémentation `node:fs`) :

```js
/** @typedef {object} CreateIo
 * @property {string} cwd                                   // absolu, POSIX
 * @property {(path: string) => string} readText
 * @property {(path: string, text: string) => void} writeText // crée les dossiers parents
 * @property {(path: string) => boolean} exists
 * @property {(dir: string) => { name: string, isDirectory: () => boolean }[]} readdir
 * @property {(message: string) => void} out
 * @property {(message: string) => void} err
 */
```

Chemins absolus résolus par `node:path` `posix` (`resolveIn(io, rel)`), exportée ici.

## `src/lib/hash.mjs`

`sha256(text)` → hexadécimal (`node:crypto`), sur les octets UTF-8, sans normaliser les fins de
ligne.

## `src/lib/registry.mjs`

Les éléments sont les fragments `packages/astro/registry/items/*.json` (schéma shadcn, lis
`stack.json`) du paquet `@paulperigault/astro` **installé**.

- `PACKAGE_NAME = '@paulperigault/astro'`, `REPO_PREFIX = 'packages/astro/'`.
- `packageRoot(io, from)` : `from` (relatif à `io.cwd` ou absolu) sinon
  `<cwd>/node_modules/@paulperigault/astro` ; absent ou sans `registry/items` → `Error` dont le
  message donne la commande `npm i @paulperigault/astro`.
- `loadItems(io, root)` → éléments triés par `name` ; fragment invalide (JSON, `name`, `files`
  manquants) → `Error` avec le chemin.
- `findItem(items, query)` : correspondance insensible à la casse sur `name` ou `title`
  (`Button` = `button`) ; introuvable → `Error` listant les noms disponibles.
- `itemFiles(item)` → chemins relatifs à la racine du paquet (`src/layout/Stack.astro`) : le préfixe
  `REPO_PREFIX` est retiré ; un chemin qui sort du paquet (`..`, absolu) → `Error`.
- `packageVersion(io, root)` → `version` du `package.json` du paquet.

## `src/lib/lock.mjs`

- `LOCK_FILE = 'pp-ds.lock.json'`, format :
  `{ "lockfileVersion": 1, "items": { "stack": { "package": "@paulperigault/astro", "version": "0.0.0", "files": [{ "source": "src/layout/Stack.astro", "path": "src/components/pp/layout/Stack.astro", "sha256": "…" }] } } }`.
- `readLock(io)` (absent → verrou vide ; `lockfileVersion` inconnu → `Error`), `withItem(lock, name, entry)`
  (pure, ne mute pas), `serializeLock(lock)` (clés d'`items` triées, 2 espaces, saut de ligne final).

## `src/lib/plan.mjs`

Un plan = `[{ path, content, overwrite? }]` (chemins relatifs à `io.cwd`).

- `applyPlan(io, plan, { dryRun, force })` → code : les écrasements d'un fichier existant sans
  `overwrite: true` ni `force` sont des **conflits** : tous listés sur `io.err`, **rien n'est
  écrit**, code `1`. `dryRun` : chaque ligne `créerait <path>` ou `écraserait <path>` sur `io.out`,
  rien n'est écrit, code `0`. Sinon écrit et affiche `écrit <path>`, code `0`.

## `test/fake-io.mjs`
