Contexte : `docs/benchmark/gap.md` (lot L12, performance mobile). La doc est servie par
`apps/docs/e2e/serve.mjs` ; la matrice d'appareils est dans `apps/docs/e2e/devices.ts` ;
`apps/docs/e2e/web-vitals.ts` fournit `injectVitals`, `readCls`, `isLcp`.

1. `DocsLayout.astro` : précharge **la seule** police du corps, avec
   `<link rel="preload" as="font" type="font/woff2" crossorigin href={…}>`. L'URL vient de
   `import bodyFont from '@fontsource-variable/atkinson-hyperlegible-next/files/atkinson-hyperlegible-next-latin-wght-normal.woff2?url'`
   (vérifie que le fichier existe dans `node_modules` et que l'URL émise correspond bien au
   fichier référencé par le `@font-face` de `packages/css/src/fonts.css` ; sinon adapte).
   Aucun attribut `style`, aucune ressource tierce.
2. `e2e/perf.spec.ts` : projet `chromium` seulement, viewport 360 × 800, tactile, CPU ralenti ×4
   (`Emulation.setCPUThrottlingRate`) et réseau « Slow 4G » (`Network.emulateNetworkConditions`,
   latence 150 ms, 1,6 Mbit/s descendant) via CDP. Sur `/` et sur une page de composant
   (`/components/button/`) : LCP ≤ 2,5 s, CLS ≤ 0,1, INP ≤ 200 ms (clic sur le bouton du menu
   mobile, entrée `event` du `PerformanceObserver` avec `durationThreshold`), JavaScript total
   ≤ 1 Ko gzip (somme des réponses `script`, `zlib.gzipSync`), une seule police préchargée
   (`link[rel=preload][as=font]` = 1) et le corps rendu avec cette police.
   Constantes nommées en tête de fichier (pas de nombre magique hors `*.spec.ts`, mais nomme-les).
3. Si un budget échoue pour une vraie raison (pas un artefact de mesure), ne desserre pas le
   budget : corrige la cause dans tes fichiers si c'est possible, sinon explique-la dans
   « ce qui reste incertain ».

Contraintes d'`AGENTS.md` : fichiers ≤ 120 lignes, pas de `any`, `import type`, pas de `console`.
