P3 PWA, 1/3. `lib/pwa.ts` (pur) : `buildManifest(site)` renvoie le manifeste : `name` et
`short_name` (depuis `SITE_NAME` de `lib/site.ts`), `lang: 'fr'`, `start_url: '/'`, `scope: '/'`,
`id: '/'`, `display: 'standalone'`, `theme_color` et `background_color` lus dans
`@paulperigault/tokens/tokens.json` (`themeColor.light`, comme `DocsLayout.astro`), `icons` (192,
512, maskable 512, `type: 'image/png'`). Aucune valeur de couleur brute dans le code. Page
`pages/manifest.webmanifest.ts` : endpoint statique `GET` qui sérialise ce manifeste
(`Content-Type: application/manifest+json`). Test : champs requis, icônes présentes, couleurs
issues des jetons.

`scripts/pwa-icons.mjs` : génère les trois PNG avec `sharp` (déjà installé, ne pas toucher
`package.json`) **depuis `apps/docs/public/image/logo.svg` en lecture seule** : 192 et 512 carrés ;
la maskable place le logo à 80 % au centre d'un fond uni de la couleur `#14161c` du logo (lis le
SVG). Les icônes sont versionnées dans `public/pwa/` ; le script est idempotent. Test
(`node:test`) : sortie de la bonne taille, PNG valide. **Ne modifie ni ne supprime aucun favicon
ni `logo.svg`** (identité intouchable). Le `<link rel="manifest">` dans `DocsLayout.astro`
appartient à l'orchestrateur. Lance le script une fois pour produire les PNG.
