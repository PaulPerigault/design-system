`create <dossier>` de `@paulperigault/create` : génère un site Astro **minimal consommateur** du
design system. Lis le socle `packages/create/src/lib/*.mjs` et `test/fake-io.mjs` (T8.08), ainsi
que `.github/workflows/ci.yml`, `commitlint.config.mjs` et `tools/commitlint/no-tool-signature.mjs`
du dépôt (modèles à reprendre).

## Contrat de commande (commun à `create`, `add`, `eject`, `diff`)

`export function run({ positionals, dryRun, force, from, out }, ctx)` → code (`0` succès, `1`
refus ou différences, `2` usage). `ctx = { io, template }` ; ici
`template = { files: [{ path, content }], versions }`, chargé par
`loadTemplate(readIo, templatesRoot)` de `src/site/template.mjs` (lit `templates/site/**` et
`templates/versions.json` ; la CLI de T8.12 lui passera la racine réelle).

## Gabarit

- Nom de fichier : un segment commençant par `_` est écrit avec `.` (`_gitignore` → `.gitignore`,
  `_github/` → `.github/`, `_husky/` → `.husky/`), car `npm pack` écarte `.npmrc` et `.gitignore`.
- `templates/versions.json` : **versions exactes** (sans `^`) d'`astro`, `@paulperigault/css`,
  `@paulperigault/guards`, `husky`, `@commitlint/cli`, `@commitlint/config-conventional` ; relève
  celles installées dans `node_modules` du dépôt, `0.0.0` pour les paquets `@paulperigault/*`.
- `src/site/package-json.mjs` : `sitePackageJson(name, versions)` → texte JSON (2 espaces, saut de
  ligne final) : `private`, `type: module`, `engines.node >= 24`, scripts `dev`, `build`,
  `preview` (astro), `guard: "pp-guards all"`, `verify: "npm run guard && astro build"`,
  `prepare: "husky"` ; `dependencies` : `astro`, `@paulperigault/css` ; `devDependencies` :
  `@paulperigault/guards`, `husky`, `@commitlint/*`. Nom npm dérivé du dossier (minuscules,
  caractères hors `[a-z0-9-._]` → `-`).
- `_npmrc` : `registry=https://registry.npmjs.org/`, `save-exact=true`, `engine-strict=true`.
- `commitlint.config.mjs` + `commitlint/no-tool-signature.mjs` : Conventional Commits, sujet en
  minuscules ≤ 72, refus de `Co-authored-by` et « Generated with », sans exemption
  (`defaultIgnores: false`), autonome (copie de la règle du dépôt).
- `_husky/commit-msg` : `npx --no -- commitlint --edit "$1"`.
- `_github/workflows/ci.yml` : `permissions: contents: read`, actions épinglées par SHA comme dans
  le `ci.yml` du dépôt, `persist-credentials: false`, Node 24, `npm ci`, `npm run verify`.
- `pp-guards.config.json` : sections `tokens`
  (`node_modules/@paulperigault/tokens/generated/tokens.json`, racine `src`), `design`, `size`,
  `images` (racines `src`, `public`).
- `Base.astro` (`lang="fr"`, `import '@paulperigault/css'`, titre en prop, `<main>`), `index.astro`
  (titre, un paragraphe factuel) : zéro JS, aucun `style` en ligne, aucune valeur brute, aucun
  interdit d'`AGENTS.md`.
- `README.md` : démarrage (`npm install`, `npm run dev`, `npm run verify`), commit du lockfile
  avant la première CI.

## Commande

- Un positionnel exactement (sinon `2`). Dossier existant et non vide → refus, code `1`, rien
  écrit (même avec `--force` : on ne génère jamais par-dessus un projet).
- Plan d'écriture appliqué par `applyPlan` (donc `--dry-run` liste sans écrire), puis prochaines
  étapes sur `io.out`.

## Critères

- Test par **instantané** (`toMatchSnapshot`) de l'arborescence générée et du sha256 de chaque
  fichier, le gabarit réel étant lu en lecture seule et l'écriture faite dans `fakeIo`.
- Tests : renommage `_` → `.`, `package.json` (versions exactes, scripts), `--dry-run` n'écrit
  rien, refus d'un dossier non vide, nom npm dérivé.
- Les fichiers du gabarit passent eux aussi ESLint et Prettier du dépôt.
