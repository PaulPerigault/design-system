Deux pages. `/auteur/` « À propos de l'auteur » (brouillon à relire par Paul, première personne
interdite sauf citation : écris à la troisième personne) : Paul Périgault, DevOps / DevSecOps ;
liens vers le portfolio (`https://paulperigault.fr`, avec `rel="author"` sur au moins un lien)
et le dépôt GitHub `https://github.com/PaulPerigault` ; ce que le design system montre de sa
façon de travailler (lis `AGENTS.md`, `docs/adr/`, `docs/decisions-log.md`) ; section « Contact »
avec la ligne exacte `contact : [à compléter par Paul]`. Aucune formation, aucun employeur,
aucune date n'est affirmée. `/utiliser/` « Utiliser le design system » (technique, pas de
brouillon) : installation (`npm create @paulperigault <dossier>`, `npx @paulperigault/create add
<élément>`, `eject`, `diff` : lis `packages/create/README.md`), importer les jetons
(`@paulperigault/tokens/tokens.css`), les composants (`@paulperigault/astro/<Nom>.astro`),
contrôler avec `@paulperigault/guards` (`pp-guards all`), brancher le serveur MCP
(`packages/mcp/README.md` : `.mcp.json`, Kiro, Cursor), le registre `/r/registry.json`, `llms.txt`.
Blocs de code copiables dans `<pre tabindex="0"><code>` (avec le style de `ComponentPage`
si nécessaire : `styles/component-page.css` est déjà chargé par ce composant seulement ; ajoute
un style local scopé). Mentionne que les paquets ne sont pas encore publiés sur npmjs
(`README.md` racine, section Statut).

Règles de contenu (AGENTS.md) : français simple, phrases de 25 mots au plus, un terme par notion,
aucune formule creuse (« passionné par », « solutions innovantes »…). « Prouvé » seulement si une
source l'établit (norme, auteur, année) ; sinon « convention » ou « préférence ». N'écris que des
faits que tu lis dans le dépôt (cite le fichier ou le test qui les établit en texte) ; **n'invente
aucun chiffre, aucune date, aucun employeur, aucune formation**. Les passages à la première
personne ou parlant de Paul sont des brouillons : insère `<DraftNotice />`
(`../components/DraftNotice.astro`) en tête de page. Chaque page passe à `DocsLayout` un `title`
(format `Titre · Design system · Paul Perigault`) et une `description` unique de 120 à 160
caractères. Pas de nouveau composant ni de CSS brut : réutilise `@paulperigault/astro`
(`Alert`, `Table`, `Stack`, `Cluster`, `Prose`…, lis leurs `Props`) et les jetons `--pp-*`.
Propriétés logiques, aucun attribut `style`, cibles ≥ `--pp-size-target-min`. Fichiers ≤ 120 lignes.
Acceptation : formatage, `astro check`, build, taille ; le test e2e SEO (`seo.spec.ts`) devra
passer sur la page (un seul `<h1>`, titre et description uniques).
