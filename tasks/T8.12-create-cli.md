Point d'entrée de `@paulperigault/create`. Lis `packages/create/src/lib/*.mjs` et
`src/commands/{create,add,eject,diff}.mjs` : chaque commande expose
`run({ positionals, dryRun, force, from, out }, ctx)` ; `create` attend en plus
`ctx.template = loadTemplate(readIo, templatesRoot)` (`src/site/template.mjs`).

## `src/cli.mjs`

- `main(argv, ctx)` → code, `ctx = { io, templatesRoot, version }`. `node:util` `parseArgs` en
  mode **strict**, `allowPositionals` : `--dry-run`, `--force`, `--from <dir>`, `--out <dir>`,
  `--help`/`-h`, `--version`/`-v`.
- Commandes : `create <dossier>`, `add <élément>`, `eject <élément>`, `diff <élément>`.
  Raccourci `npm create @paulperigault <dossier>` : premier positionnel qui n'est pas une
  commande **et** seul positionnel → `create <dossier>`.
- Option non pertinente pour la commande (`--out` hors `eject`, `--force` hors `eject`,
  `--from` pour `create`) → usage, code `2`. Commande inconnue, option inconnue, argument
  manquant → usage sur `io.err`, code `2`. `--help` → usage sur `io.out`, code `0` ;
  `--version` → `ctx.version`.
- Usage court et factuel : une ligne par commande, options, exemple
  `npx @paulperigault/create eject stack`.
- `loadTemplate` n'est appelé que pour `create`.

## `bin/pp-create.mjs`

Shebang `#!/usr/bin/env node` ; construit `nodeIo({ cwd: process.cwd(), stdout, stderr })`,
`templatesRoot` depuis `import.meta.url` (`../templates`), `version` lue dans `../package.json`,
puis `process.exitCode = main(process.argv.slice(2), ctx)`. Exceptions non prévues : message sur
stderr, code `1`. Aucune autre logique.

## Critères

- Tests sans disque (`test/fake-io.mjs`) : dispatch des quatre commandes, raccourci `create`,
  options strictes, options non pertinentes, `--help`, `--version`, codes.
- Les commandes d'acceptation `node packages/create/bin/pp-create.mjs …` passent depuis la racine
  du dépôt sans rien écrire (`--dry-run`).
