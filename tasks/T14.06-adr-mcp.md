Écris `docs/adr/0003-mcp.md`, même forme que `docs/adr/0002-identite-encre.md` (statut, contexte,
décision, conséquences, alternatives), en français, factuel, 60 à 100 lignes. Lis d'abord
`docs/benchmark/systems.md` (section outillage IA : Primer `@primer/mcp`, Carbon MCP hébergé avec
OAuth, shadcn MCP) et `docs/benchmark/gap.md` n° 28 à 30. Contenu :

- **Décision maintenant** : `@paulperigault/mcp`, serveur stdio, **lecture seule**, données
  embarquées à la publication (aucun accès réseau), entrées validées (zod), outils
  `list_components`, `get_component`, `get_tokens`, `check_contrast`, `validate_snippet`,
  `search_docs`, `get_decision`. Plus le registre shadcn statique (`/r/registry.json`), qui rend
  déjà exploitable `npx shadcn@latest mcp` sans code serveur.
- **Plus tard, seulement planifié** : version distante (Cloudflare Worker, en IaC OpenTofu) ;
  conditions préalables : authentification (OAuth 2.1 ou jeton, à choisir), limitation du débit,
  coût mesuré (requêtes Workers, journaux), CSP et CORS, RGPD (aucune donnée personnelle
  journalisée), journal d'audit. Ne rien construire ni nommer de ressource réelle. Décris le plan
  en cinq étapes.
- **Sécurité** : surface d'attaque d'un serveur MCP (injection par le contenu retourné, chemins,
  exécution de code interdite : `validate_snippet` analyse du texte, il n'exécute rien).
- **Alternatives écartées** : serveur distant d'emblée ; seulement `llms.txt` ; seulement shadcn
  MCP ; pas de MCP.
- Règle éditoriale d'AGENTS.md : « prouvé » seulement avec une source (cite celles de
  systems.md) ; sinon « convention ». N'invente aucun prix, aucune limite de service : écris
  « à mesurer ».
