## Figure

`<figure class="pp-figure">` : slot par défaut (le média, en pratique un `Photo`), puis
`<figcaption>` avec `caption: string` (obligatoire, non vide sinon `TypeError`) et, si fourni,
`credit?: string` dans un `<small class="pp-figure__credit">` (texte complet fourni par le site,
ex. « Photo : … »). Légende `--pp-color-muted`, `--pp-font-size--1`, marge
`--pp-space-2xs`, `max-inline-size: var(--pp-size-measure)`.

## Scrim

Texte posé sur une photo, lisible quelle que soit la photo. Slot nommé `media` (un `Photo`) et
slot par défaut (le texte). Empilement par grille (`grid-area: 1 / 1`) ; le texte est dans un
bloc dont le **fond est le voile** : `background-color: color-mix(in srgb,
var(--pp-media-scrim-color) calc(var(--pp-media-scrim-opacity) * 100%), transparent)`, couleur
`var(--pp-media-scrim-text)`, marges `--pp-space-*`. `place?: 'start' | 'end'` (défaut `end`)
par `data-place`. Pas de dégradé, pas de flou, pas d'ombre.

`scrim.ts` (pur) : `compositeOver(veil: Rgb, opacity: number, under: Rgb): Rgb` (mélange en
sRGB gamma, comme `color-mix(in srgb)` et la composition des navigateurs) et
`worstCaseContrast({ veil, opacity, text })` : pour tout fond possible sous le voile, la
luminance du composite est entre celle du composite sur noir et celle sur blanc ; si la
luminance du texte tombe dans cet intervalle le pire cas vaut 1, sinon c'est le minimum des
deux extrémités (`relativeLuminance` de `@paulperigault/tokens/contrast`, rapport WCAG 2).

## Tests

`Scrim.test.ts` : lit `--pp-media-scrim-color`, `-text`, `-opacity` dans
`@paulperigault/tokens/tokens.json` (`base`, chaînes `oklch(…)` → `parseOklch` + `oklchToSrgb`
de `@paulperigault/tokens/color`) ; **pire cas ≥ 4,5:1** (WCAG 1.4.3) et contraste sur fond
blanc pur ≥ 4,5:1 ; un voile trop léger (opacité 0,2) donne < 4,5 (le test sait échouer) ;
`compositeOver` aux bornes (opacité 0 et 1) ; rendu : texte présent, `data-place`, aucun
`style` ; le CSS du composant (lu dans le fichier source) contient `color-mix` sur les trois
tokens et aucun `gradient`, `blur`, `shadow`. `Figure.test.ts` : structure figure/figcaption,
crédit absent ou présent, légende vide refusée, aucun `style`.
