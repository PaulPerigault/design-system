`templates/`, T8.09) est intégré et approuvé ; les revues ont laissé ces remarques, à traiter.
Ne change pas le contrat de commande (`run({ positionals, dryRun, … }, { io, template })`) ni
`loadTemplate`. Mets l'instantané à jour (`npx vitest run … -u`) et vérifie que seules les
empreintes des fichiers modifiés changent.

   le dossier entre guillemets simples (avec `'\''` pour une apostrophe) dès qu'il contient un
   caractère hors `[\w./-]`. Test.
2. `template.mjs` : ignorer toute entrée du gabarit dont le nom commence par `.` (`.DS_Store` du
   Finder), puisque les fichiers point sont codés par `_`. Test avec un faux `readdir`.
3. Gabarit `ci.yml` : `npm ci --ignore-scripts` (même règle que la CI du dépôt), puis
   `npm run verify`.

   alors que `@paulperigault/tokens` n'est qu'une dépendance transitive (hissage non garanti).

   `package.json` mis à jour.

   `npm run guard` (`pp-guards all`, configuration `pp-guards.config.json`).

`validate-npm-package-name`), le commentaire de `npmName` le dit déjà.
