   Rien d'autre ne change.
2. `apps/docs/e2e/layout.spec.ts` (Playwright, même config que les autres specs) : sur les pages
   `/components/<primitive>/`, vérifie le **CSS réellement appliqué** (`getComputedStyle`) :
   Stack (`margin-block-start` du 2e enfant = valeur de `--pp-space-m`, 1er enfant 0), Cluster
   (`gap`), Grid (`display: grid`), Container (`max-inline-size`), Sidebar et Switcher
   (`flex-wrap: wrap`), Center (`margin-inline` auto). Ce test attrape un sélecteur scopé qui
   n'atteint pas les enfants du slot (défaut constaté au pilote T1.01).
