`@paulperigault/css` : la couche CSS commune, bâtie **uniquement** sur les variables `--pp-*`
générées dans `@paulperigault/tokens/tokens.css` (liste : `packages/tokens/generated/tokens.json`).
Aucune couleur, taille, espacement, rayon ou durée brute.

- `index.css` : `@import '@paulperigault/tokens/tokens.css';`, `./fonts.css`, `./base.css`,
  `./print.css`. **Ne pas** importer `tailwindcss` (le site consommateur le fait) ; `theme.css`
  est importé à part par les sites Tailwind.
- `base.css` (`@layer base`) : fond `--pp-color-bg`, texte `--pp-color-fg`, famille
  `--pp-font-family-sans`, corps `--pp-font-size-0` et `--pp-font-line-height-body`, titres
  `--pp-font-line-height-heading` et `text-wrap: balance`, paragraphes `text-wrap: pretty`,
  `code, kbd, samp, pre` en `--pp-font-family-mono`, `time` en chiffres tabulaires, liens
  soulignés (`text-underline-offset` en `em`), `::selection` accent / on-accent,
  `:focus-visible { outline: var(--pp-size-focus-width) solid var(--pp-color-focus); outline-offset: var(--pp-size-focus-offset); }`,
  `scroll-behavior: smooth` seulement sous `prefers-reduced-motion: no-preference`, et sous
  `prefers-reduced-motion: reduce` : animations et transitions ramenées à 0 (`*, ::before, ::after`).
  Propriétés logiques uniquement. Aucune ombre, aucun dégradé.
- `print.css` (`@media print`) : thème clair forcé (`color-scheme: light` sur `:root` et les deux
  `data-theme`), adresse des liens externes après le lien, `break-inside: avoid` sur `li`,
  `figure`, `pre`, `table`.
- `theme.css` (Tailwind v4) : `@custom-variant js (:root.js &);` et `@theme inline { … }` qui
  **supprime** les valeurs par défaut (`--color-*: initial; --font-*: initial; --text-*: initial;
--shadow-*: initial; --drop-shadow-*: initial; --radius-*: initial; --spacing-*: initial;`) puis
  expose chaque token : `--color-bg: var(--pp-color-bg)` … (tous les rôles de couleur, statuts
  compris), `--font-sans`, `--font-mono`, `--text-sm` … `--text-4xl` (depuis `--pp-font-size-*`),
  `--spacing-3xs` … `--spacing-3xl`, `--radius-control`, `--radius-surface`, `--container-page`,
  `--container-measure`.
- Test `css.test.mjs` : chaque `var(--pp-…)` des quatre fichiers existe dans `tokens.json` ;
  aucune couleur littérale (`#…`, `rgb(`, `oklch(`), aucun `px` hors `0`, aucune propriété
  physique (`margin-left`, `padding-right`, `width`… → logiques), `theme.css` réinitialise bien
  les palettes par défaut.
