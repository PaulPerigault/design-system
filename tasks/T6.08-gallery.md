Galerie d'images accessible (WCAG 2.2 AA), **zéro JavaScript**. Lis d'abord `AGENTS.md`,
`packages/astro/src/media/Photo.astro`, `frame.css`, `types.ts`, `presets.ts` (à réutiliser sans
les modifier), `packages/astro/src/layout/Grid.astro`, `packages/astro/test/Photo.test.ts`,
`apps/docs/e2e/forms.spec.ts` et `helpers.ts` (style e2e, ne pas modifier `helpers.ts`).

## Props

`id: string` (préfixe des identifiants), `items: { src: ImageMetadata; alt: string; caption?:
string }[]` (alternative **obligatoire** : une galerie est du contenu), `ratio?: Ratio` (défaut
`square`), puis union : `{ enlarge?: false }` ou `{ enlarge: true; labels: { open: string;
close: string } }` (aucun texte en dur : les libellés viennent du site).

## Rendu

- `<div class="pp-gallery">` (`container-type: inline-size`) contenant
  `<ul role="list" class="pp-gallery__list">` (`list-style: none`, d'où `role="list"`), un `<li>`
  par image avec `Photo` (`layout="third"`, ratio transmis).
- Grille en **container queries** : 1 colonne, 2 colonnes à partir de `19rem`, 3 à partir de
  `38rem`. CSS n'accepte pas `var()` dans une condition `@container` : ces deux seuils sont les
  seules valeurs littérales permises, commentées (`--pp-size-measure / 2` et
  `--pp-size-measure`), et le test vérifie qu'elles égalent les tokens. Espacement `--pp-space-s`.
- `enlarge` : la vignette est dans un bouton d'invocation HTML, sans script :
  `<button type="button" commandfor="{id}-{n}" command="show-modal">`. Nom accessible : le
  libellé `labels.open` suivi de l'alternative (texte masqué visuellement ou `aria-label`).
  Cible ≥ `--pp-size-target-min`, focus hérité de `@paulperigault/css`.
- `GalleryDialog.astro` rend, par image, `<dialog id="{id}-{n}" closedby="any">` nommé par
  `aria-label` (l'alternative), avec un `Photo` sans ratio (`layout="page"`, ratio intrinsèque,
  chargé en `lazy` donc seulement à l'ouverture), la légende si présente, et un bouton de
  fermeture `<button type="button" commandfor="{id}-{n}" command="close">` au texte
  `labels.close`. Échap ferme ; le navigateur rend le focus au bouton d'origine.
  Fond du dialog : `--pp-color-bg`, `::backdrop` en `--pp-color-fg` mélangé (`color-mix`), pas
  de flou ni d'ombre. Le dialog ne déborde pas du viewport (`max-block-size`, image contenue).
- Aucun `<script>`, aucun attribut `style`, identifiants uniques.

## Tests

`Gallery.test.ts` (`renderDom`, fixtures) : `role="list"`, un `li` par image, sans `enlarge` :
ni `button` ni `dialog` ; avec : `commandfor`/`command` qui pointent vers des `dialog`
existants, boutons de fermeture, noms accessibles, identifiants uniques ; aucun `script`, aucun
`style` ; seuils `@container` du fichier source égaux aux tokens ; `expectTypeOf` : `enlarge`
sans `labels` refusé.

`apps/docs/e2e/gallery.spec.ts` (Playwright, contexte **JavaScript désactivé** compris) : sur
`/components/gallery/`, Tab jusqu'à une vignette, Entrée ouvre le dialog (`open`), le focus est
dans le dialog, Échap le ferme et le focus revient sur la vignette ; le bouton de fermeture
ferme aussi ; à 390 px de large une colonne, à 1280 px trois colonnes (mesure des `li`).
