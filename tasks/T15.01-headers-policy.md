Brique de la mission « sécurité du site » : en-têtes **indépendants de l'hébergeur**. Ce lot ne
fait que la logique pure (ESM, JSDoc, aucune lecture de disque, aucun `console`) ; d'autres
tâches branchent les adaptateurs (Cloudflare, Netlify, Vercel, Nginx) et la CLI. Vitest `docs`
lit `scripts/**/*.test.mjs`. Respecte les limites d'`AGENTS.md` (fichier ≤ 120 lignes, fonction
≤ 40, complexité ≤ 8, aucun nombre magique : constantes nommées).

Modèle de données (à exporter en `@typedef` depuis `policy.mjs`, les adaptateurs le consommeront) :

```js
/** @typedef {[name: string, value: string]} Header */
/** @typedef {{ path: string, headers: Header[] }} HeaderRule  // path: '/*' ou '/_astro/*' */
/** @typedef {{ from: string, to: string, status: number }} Redirect */
```

1. `hashes.mjs` : `inlineHashes(html)` → `{ styles: string[], scripts: string[] }`, hachages CSP
   `'sha256-<base64>'` (SHA-256 du **contenu exact** de chaque `<style>` / `<script>` sans `src`,
   via `node:crypto`), triés, sans doublon ; `scripts` ignore les `<script src>` et les
   `type="application/ld+json"` (données, non exécutées). `inlineStyleAttributes(html)` renvoie le
   nombre d'attributs `style=""` (le test de build exigera 0). Tests : valeur de hachage connue
   (calcule-la avec `openssl dgst -sha256 -binary | base64` dans ton test, valeur écrite en dur),
   doublons, script externe ignoré, JSON-LD ignoré.
2. `policy.mjs` :
   - `contentSecurityPolicy({ styleHashes, scriptHashes })` → chaîne : `default-src 'none'`,
     `script-src 'self' 'wasm-unsafe-eval'` + hachages de scripts, `style-src 'self'` + hachages de
     styles, `img-src 'self' data:`, `font-src 'self'`, `connect-src 'self'`, `manifest-src 'self'`,
     `worker-src 'self'`, `base-uri 'none'`, `form-action 'self'`, `frame-ancestors 'none'`,
     `object-src 'none'`, `upgrade-insecure-requests`. **Jamais** `'unsafe-inline'`, `'unsafe-eval'`
     ni source en `*` ou `https:` (un test le vérifie sur la sortie). `'wasm-unsafe-eval'` : la
     recherche Pagefind charge du WebAssembly (documente-le en commentaire).
   - `securityHeaders()` → `Header[]` fixes : `Strict-Transport-Security: max-age=63072000;
includeSubDomains` (pas de `preload`, décision d'apex du propriétaire), `X-Content-Type-Options:
nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy` (refuse
     accéléromètre, lecture automatique, caméra, capture d'écran, géolocalisation, gyroscope,
     magnétomètre, microphone, paiement, USB ; `fullscreen=(self)`), `Cross-Origin-Opener-Policy:
same-origin`, `Cross-Origin-Resource-Policy: same-origin`, `Cross-Origin-Embedder-Policy:
require-corp`, `X-Frame-Options: DENY`, `X-Permitted-Cross-Domain-Policies: none`.
   - `buildRules({ styleHashes, scriptHashes })` → `HeaderRule[]` : `/*` = `securityHeaders()` +
     CSP + `Cache-Control: public, max-age=0, must-revalidate` ; `/_astro/*` =
     `Cache-Control: public, max-age=31536000, immutable`.
   - `REDIRECTS` : `[{ from: '/index.html', to: '/', status: 301 }]`.
   - `REQUIRED_HEADERS` : tableau des noms d'en-têtes qui doivent figurer sur `/*` (source unique
     pour les tests des adaptateurs et le test de build).
     Tests : chaque directive attendue, absence des valeurs interdites, `REQUIRED_HEADERS` ⊂ en-têtes
     de `/*`, hachages injectés au bon endroit, règle `/_astro/*` immuable.
