Les README de `packages/guards` et `packages/create` (T8.13) contiennent des erreurs de fait.
Corrige-les en lisant le code ; chaque option, défaut, format et exemple cité doit exister
(`packages/guards/src/**`, `packages/create/src/**`, `pp-guards.config.json`). Ne cite aucune
phrase générique ni aucun emoji en toutes lettres (les README sont contrôlés par
`pp-guards design`). Français, factuel, sans formule creuse.

## `packages/guards/README.md`

- `tokens` : contrôle que chaque `var(--pp-…)` désigne un token de `tokens.json` (erreur, code 1)
  et signale les tokens jamais utilisés (avertissement, code 0) ; ce n'est pas un contrôle des
  valeurs brutes.
- Les racines sont des **positionnels** (`pp-guards design src`), pas un drapeau `--roots`. Liste
  les drapeaux réels de chaque `cliOptions` : `design` (`--extensions`, `--allow`, `--disable`),
  `size` (`--max`, `--ext`), `images` (`--allow`, `--maxKb`, `--budgets` en JSON), `layers`
  (configuration seulement), `tokens` (`--tokens`), plus `--config` et `--help` partout.
- `design` : la police mono est permise (ADR-0002) ; `color-literal` vise les valeurs CSS ; renvoie
  aux fichiers `src/design/*.mjs` pour les listes exactes.
- `layers` : couches ordonnées de la plus basse à la plus haute, `paths` et `packages`, import
  refusé vers une couche plus haute, échec si aucun fichier n'appartient à une couche.
- `images` : `<img>` brut et `background-image: url(` interdits hors `allow` (défaut
  `src/media`) ; métadonnées EXIF/GPS/XMP des JPEG et PNG avec la commande de nettoyage
  `exiftool` ; budget `maxKb` (défaut 500, 1 Ko = 1024 octets) et `budgets` par chemin. Rien sur
  les SVG en ligne.
- Branchement : `"guard": "pp-guards all"` dans les scripts, appelé par `verify` (comme le site
  généré par `@paulperigault/create`).
- ESLint : `import { designConfig } from '@paulperigault/guards/eslint'` (export demandé à
  l'orchestrateur), exemple avec `typescript-eslint` (`tseslint.config(...)`), et
  `designRules` / `testRelaxations`.

  `@paulperigault/guards` dans `verify`, Husky, commitlint, CI) : lis le gabarit
  `templates/site/` et `src/site/package-json.mjs`.
- Format exact de `pp-ds.lock.json` (`lockfileVersion`, `items` indexés par le `name` du registre
  en minuscules), lu dans `src/lib/lock.mjs`.
- Extrait d'import exact (`import Stack from '@paulperigault/astro/Stack.astro';`), lu dans
  `src/commands/snippet.mjs`.
- Codes de sortie par commande (`diff` : `1` s'il y a des différences, `2` si non éjecté).
- Retire l'option `--config` (elle n'existe pas) et la section « Architecture interne ».
