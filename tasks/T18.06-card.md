Composant tier 2, accessible (WCAG 2.2 AA), mobile d'abord, **zéro JavaScript**, dans
`packages/astro/src/content/`. Lis d'abord `AGENTS.md`, puis `packages/astro/src/feedback/Status.astro`
(modèle de variantes `data-*`, de tokens et de commentaire d'en-tête) et son test
`packages/astro/test/Status.test.ts` (`renderDom` de `./render`). Règles : aucun attribut `style`,
`:global()` pour le contenu de slot, jetons `--pp-*` uniquement (liste dans
`packages/tokens/generated/tokens.json` : n'invente aucun jeton), propriétés logiques, aucun texte
en dur (libellés en props), jamais la couleur seule, pas de dégradé ni d'ombre ni de flou.
Fichiers ≤ 120 lignes (découpe si besoin).

## Card

Carte riche : `title: string`, `href?: string`, `headingLevel?: 2|3|4` (défaut 3), slots `media` (facultatif), par défaut (texte), `footer` (facultatif, ex. étiquettes). Quand `href` est donné, **un seul lien** couvre toute la carte (motif du lien étendu : le lien est dans le titre et son `::after` s'étend sur la carte, `position: relative` sur la racine) ; les éléments interactifs du slot `footer` passent au-dessus (`position: relative`, `z-index` par jeton si nécessaire) et restent utilisables. Pas d'ombre (interdit), bordure fine pleine, rayon par jeton. Focus visible sur la carte entière (`:focus-visible` du lien, anneau par jeton existant, lis `packages/css/src` ou les composants Button/Photo). Le contenu du slot est visé avec `:global()`.

Le champ `Props` documente chaque propriété. L'export `@paulperigault/astro/Card.astro`, l'entrée
de navigation et `meta.tokens` du fragment de registre sont posés par l'orchestrateur : dans
`registry/items/card.json`, mets le schéma shadcn comme `status.json` avec `"tokens": []` (le
script `npm run registry` le recalcule). Test : rôles, noms accessibles, attributs selon les
props et défauts, aucun attribut `style`, un cas limite par prop.

Page de doc `apps/docs/src/pages/components/card.astro` sur le gabarit
`../../components/ComponentPage.astro` exactement comme `components/status.astro` (lis-la :
`slug`, `title`, `summary`, `use`, `avoid`, `snippet`, `a11y` avec ses quatre listes, `evidence`
avec liens vers la norme WCAG ou l'APG qui s'applique, slot par défaut = exemples) ; les exemples
vivants sont dans `components/examples/card.astro`. Importe par l'export du paquet. Français
simple, phrases de 25 mots au plus, faits seulement. Les affirmations d'accessibilité citent un
critère WCAG numéroté.
