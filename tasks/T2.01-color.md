Module de couleur de `@paulperigault/tokens` (export `@paulperigault/tokens/color`, déjà déclaré).
JavaScript ESM pur (`.mjs`, aucune dépendance, exécutable par Node sans compilation) avec ses
types dans `color.d.mts`. Les sites et le générateur de tokens l'importent.

## API (noms exacts)

- `parseOklch(text)` : `'oklch(0.47 0.19 270.7)'` ou `'oklch(47% 0.19 270.7)'` → `{ l, c, h }`
  (`l` dans [0, 1]) ; texte invalide → `TypeError` explicite.
- `formatOklch({ l, c, h })` → `'oklch(47% 0.19 270.7)'` (l en %, 4 décimales au plus, sans zéros
  inutiles).
- `oklchToLinearSrgb({ l, c, h })` → `{ r, g, b }` linéaires (formules CSS Color 4 : OKLCH → Oklab
  → LMS → sRGB linéaire, matrices de Björn Ottosson, constantes nommées).
- `linearToGamma(c)` / `gammaToLinear(c)` (fonction de transfert sRGB, seuils 0.0031308 / 0.04045).
- `oklchToSrgb(color)` → `{ r, g, b }` gamma, dans [0, 1] ; `inSrgbGamut(color, epsilon = 1e-4)`.
- `toHex(color)` → `'#rrggbb'` ; **lève une `RangeError`** si la couleur est hors gamut sRGB (pas
  de rognage silencieux : la palette doit être dans le gamut, c'est une règle du design system).
- `hexToOklch('#rrggbb')` → `{ l, c, h }` (h dans [0, 360), 0 pour un gris).

## Tests (vecteurs de référence, tolérance 1e-3 sur l, c ; 0,5° sur h ; hex exact)

- `#ffffff` ↔ `oklch(1 0 0)`, `#000000` ↔ `oklch(0 0 0)`.
- `#ff0000` → `oklch(0.62796 0.25768 29.2339)` ; `#00ff00` → `oklch(0.86644 0.29483 142.4953)` ;
  `#0000ff` → `oklch(0.45201 0.31321 264.0520)` (CSS Color 4, exemples d'Oklab).
- Aller-retour `hexToOklch` → `toHex` exact sur `#14161c`, `#3749c3`, `#9fb4f8`, `#f9fafd`.
- `oklch(0.7 0.4 140)` hors gamut : `inSrgbGamut` faux, `toHex` lève une `RangeError`.
- `parseOklch` : formes nombre et pourcentage, espaces multiples, refus de `rgb(0 0 0)`.

Fichiers ≤ 120 lignes, fonctions ≤ 40 lignes, pas de nombre magique non nommé (constantes
nommées : matrices, seuils, exposants). Cite la source des matrices en commentaire.
