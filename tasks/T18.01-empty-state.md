## EmptyState

État vide : `title: string`, `headingLevel?: 2|3|4` (défaut 2), slot par défaut = explication, slot `action` facultatif (un lien ou un Button fourni par l'intégrateur). Rendu `<section>` avec `aria-labelledby` vers le titre, bordure `--pp-*` en pointillé interdite (décor) : bordure pleine fine, fond `--pp-color-surface`. Variante `data-align="start" | "center"` (défaut `start`). Aucune icône décorative.

Le champ `Props` documente chaque propriété. L'export `@paulperigault/astro/EmptyState.astro`, l'entrée
de navigation et `meta.tokens` du fragment de registre sont posés par l'orchestrateur : dans
`registry/items/empty-state.json`, mets le schéma shadcn comme `status.json` avec `"tokens": []` (le
script `npm run registry` le recalcule). Test : rôles, noms accessibles, attributs selon les
props et défauts, aucun attribut `style`, un cas limite par prop.

Page de doc `apps/docs/src/pages/components/empty-state.astro` sur le gabarit
`../../components/ComponentPage.astro` exactement comme `components/status.astro` (lis-la :
`slug`, `title`, `summary`, `use`, `avoid`, `snippet`, `a11y` avec ses quatre listes, `evidence`
avec liens vers la norme WCAG ou l'APG qui s'applique, slot par défaut = exemples) ; les exemples
vivants sont dans `components/examples/empty-state.astro`. Importe par l'export du paquet. Français
simple, phrases de 25 mots au plus, faits seulement. Les affirmations d'accessibilité citent un
critère WCAG numéroté.
