Briques **pures** du pipeline d'images de `@paulperigault/astro` (dossier
`packages/astro/src/media/`), utilisées ensuite par `Photo`, `ArtDirection` et `Gallery`
autour de `<Picture>` / `getImage()` d'`astro:assets` (Astro 7.4, `node_modules/astro`). Lis
d'abord `AGENTS.md`, `packages/astro/src/lib/variants.ts` (style), `tsconfig.base.json`
(`strictest`, `exactOptionalPropertyTypes`) et `packages/tokens/generated/tokens.json`.
Aucun nombre magique : constantes nommées et commentées. Fichiers ≤ 120 lignes, fonctions ≤ 40.

## `types.ts` (types seulement)

- `Ratio = 'portrait' | 'square' | 'landscape' | 'wide'` (tokens `--pp-ratio-*`).
- `Focal` : `center`, `top`, `bottom`, `left`, `right`, `top-left`, `top-right`,
  `bottom-left`, `bottom-right` (union de chaînes).
- `MediaLayout` : `page`, `measure`, `half`, `third`, `avatar` ; `MediaKind` : `photo`,
  `capture`, `illustration` ; `Breakpoint` : `narrow`, `medium`.
- `AltProps` : union discriminée de `{ alt: string; decorative?: never }` et de
  `{ decorative: true; alt?: never }` : impossible d'omettre les deux ou de passer les deux.

## `checks.ts`

- `altOf(props: AltProps): string` : `''` si `decorative`, sinon `alt` ; lève une `TypeError`
  explicite si `alt` est vide ou blanc (utiliser `decorative`).
- `assertLocal(src: unknown): asserts src is ImageMetadata` : lève si `src` est une chaîne
  (URL distante interdite) ou n'a pas `src`, `width`, `height`, `format`.
- `imagePath(src: ImageMetadata): string | undefined` : chemin disque de l'image source. Astro
  7.4 le pose en propriété **non énumérable** `fsPath` (voir
  `node_modules/astro/dist/assets/utils/image-asset.js`) ; lecture typée sans `any`.

## `presets.ts` (valeurs lues dans `@paulperigault/tokens/tokens.json`, section `base`)

Conversion rem → px avec `ROOT_FONT_PX = 16` (taille par défaut des navigateurs, convention) ;
lever si un token manque ou n'est pas en `rem`. Largeurs de référence : `page` =
`--pp-size-page`, `measure` = `--pp-size-measure`, `half` = page / 2, `third` = page / 3,
`avatar` = `--pp-space-3xl`.

- `sizesFor(layout)` : `page` → `(min-width: 72rem) 72rem, 100vw` ; `measure` →
  `(min-width: 38rem) 38rem, 100vw` ; `half` → `(min-width: 72rem) 36rem, 100vw` ; `third` →
  `(min-width: 72rem) 24rem, 100vw` ; `avatar` → `6rem`. Chaînes construites depuis les tokens.
- `widthsFor(layout, sourceWidth)` : `{1, 2} ×` largeur de référence (`DENSITIES = [1, 2]`),
  plus `{1, 2} × measure` pour les presets fluides (`100vw` sous la mesure) ; entiers, triés,
  sans doublon, `≤ sourceWidth` ; jamais vide (au pire `[sourceWidth]`).
- `qualityFor(kind)` : photo 70, capture 90, illustration 80 (préférence, à commenter).
- `FORMATS = ['avif', 'webp'] as const` ; `fallbackFormat(kind)` : `jpg` pour photo, `png`
  sinon (le défaut d'Astro serait `png`, trop lourd pour une photo).
- `mediaFor(breakpoint)` : `narrow` → `(width < 38rem)`, `medium` → `(width < 72rem)`.
- `ratioValue(ratio)` : nombre lu dans `--pp-ratio-*`.

## `dominant.ts`

`dominantColor(input: string | Uint8Array, deps?)` → `Promise<string | undefined>` : couleur
dominante `#rrggbb` (minuscules) via `sharp(input).stats()` → `dominant`. `deps.load` injecte
le chargement de `sharp` (défaut `() => import('sharp')`, déjà dans `node_modules`, ne rien
installer). Renvoie `undefined` si `sharp` est absent ou si le fichier est illisible (le
composant retombe alors sur `--pp-color-media-placeholder`) ; cache par chemin. Pas de flou.

## Tests (Vitest, ≤ 120 lignes chacun)

Valeurs exactes de chaque preset contre `tokens.json` ; `widthsFor` plafonné et non vide ;
`altOf` (trois cas) et `expectTypeOf` / `// @ts-expect-error` sur `AltProps` (ni l'un ni
l'autre, les deux) ; `assertLocal` refuse une URL ; `imagePath` sur un objet à `fsPath` non
énumérable ; `dominantColor` avec un faux `sharp`, avec un `sharp` qui lève, et avec le vrai
`sharp` sur une image créée en mémoire (`sharp({ create: { … background } }).png().toBuffer()`)
dont la dominante attendue est connue ; cache (un seul appel au chargeur).

Dépendance `sharp` de `@paulperigault/astro` : ne pas toucher à `package.json` (fichier
partagé) ; signale-la dans ton compte rendu.
