Fichiers ≤ 120 lignes (découpe si besoin).

## Pagination

Pagination : `label: string` (nom du repère, ex. « Pagination »), `items: { label: string; href: string; current?: boolean }[]`, `previous?: { label: string; href: string }`, `next?: { label: string; href: string }`. Rendu `<nav aria-label={label}>` + `<ul role="list">` ; la page courante porte `aria-current="page"` (et n'est pas un lien cliquable : `<span>`), précédent/suivant en liens. Cibles ≥ `--pp-size-target-min`. Les libellés viennent des props (aucun texte en dur). `Pagination` ne calcule pas les pages ; ajoute une fonction pure exportée `pageWindow(total, current, around = 1)` dans `packages/astro/src/navigation/pagination.ts` (renvoie les numéros affichés et les `null` d'ellipsis) avec test dans `packages/astro/test/pagination.test.ts`.

Le champ `Props` documente chaque propriété. L'export `@paulperigault/astro/Pagination.astro`, l'entrée
de navigation et `meta.tokens` du fragment de registre sont posés par l'orchestrateur : dans
`registry/items/pagination.json`, mets le schéma shadcn comme `status.json` avec `"tokens": []` (le
script `npm run registry` le recalcule). Test : rôles, noms accessibles, attributs selon les
props et défauts, aucun attribut `style`, un cas limite par prop.

Page de doc `apps/docs/src/pages/components/pagination.astro` sur le gabarit
`../../components/ComponentPage.astro` exactement comme `components/status.astro` (lis-la :
`slug`, `title`, `summary`, `use`, `avoid`, `snippet`, `a11y` avec ses quatre listes, `evidence`
avec liens vers la norme WCAG ou l'APG qui s'applique, slot par défaut = exemples) ; les exemples
vivants sont dans `components/examples/pagination.astro`. Importe par l'export du paquet. Français
simple, phrases de 25 mots au plus, faits seulement. Les affirmations d'accessibilité citent un
critère WCAG numéroté.
