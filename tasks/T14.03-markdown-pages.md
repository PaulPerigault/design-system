gap.md n° 30. Chaque page `dist/<chemin>/index.html` doit avoir son jumeau Markdown
`dist/<chemin>.md` (`/components/button/` → `dist/components/button.md` ; l'accueil →
`dist/index.md`), plus `dist/llms-full.txt` (toutes les pages concaténées). Lecture par des IA :
exactitude et sobriété avant tout. Aucune dépendance à installer : `node:fs`, `node:path` seuls.
Le script est lancé **après** `astro build` (l'orchestrateur ajoute la commande au `build`).
Le projet Vitest `docs` ne lit que `src/**/*.test.ts` : l'orchestrateur ajoute
`scripts/**/*.test.mjs` à sa configuration ; en attendant, lance ton test avec
`npx vitest run --root apps/docs scripts/html-to-markdown.test.mjs`.

1. `scripts/html-to-markdown.mjs` (pur, ESM, JSDoc, testé) : `htmlToMarkdown(html)` convertit le
   contenu de `<main>` : `h1`–`h4` (`#`…), `p`, `ul`/`ol`/`li` (imbriqués), `a` (`[texte](href)`,
   les liens relatifs deviennent absolus avec `https://ds.paulperigault.dev`), `strong`, `em`,
   `code`, `pre > code` (bloc clôturé), `table` (légende en italique puis tableau à barres,
   en-têtes de `th`), `dl`, `blockquote`, `img` (`alt`), entités HTML décodées. Ignore :
   `script`, `style`, `svg`, `nav`, `dialog`, `template`, `button`, `input`, `[hidden]`,
   `[aria-hidden="true"]`. Aucune erreur sur un HTML malformé (dégrade en texte).
   Pas d'analyseur HTML complet : un petit tokenizer par balises suffit, il est testé.
   Fonctions ≤ 40 lignes, complexité ≤ 8 : découpe en petites fonctions.
2. `scripts/markdown.mjs` : lit `dist/` (argument `--dist`, défaut `dist`), pour chaque
   `index.html` extrait le `<main>` et le `<title>`, écrit le `.md` (ligne 1 `# Titre`, ligne
   `Source : <URL canonique>`, puis le contenu), et `llms-full.txt` (pages séparées par une ligne
   `---`, ordre : accueil, puis alphabétique). Résumé sur `process.stdout` : nombre de pages.
   `FS` injecté dans une fonction `run({ dist, read, write, list })` exportée, et appelée sous
   `import.meta.main`.
3. Tests : chaque balise ci-dessus, liens relatifs, tableau, bloc de code, élément ignoré, HTML
   malformé, et `run` avec un FS en mémoire (une page → un `.md` + `llms-full.txt`).

Contraintes : fichiers ≤ 120 lignes (découpe en modules dans `apps/docs/scripts/` : tu peux
ajouter `apps/docs/scripts/markdown-*.mjs` si besoin, dis-le dans « ce qui reste incertain »),
pas de `any`, pas de nombre magique, français.
