Lis `apps/docs/scripts/headers/policy.mjs` (T15.01) : types `Header`, `HeaderRule`, `Redirect`,
`buildRules`, `REDIRECTS`, `REQUIRED_HEADERS`. Chaque adaptateur est **pur** :
`render(rules, redirects)` → texte (`vercel.mjs` : objet JSON sérialisable), sans disque. Les
hébergeurs sont choisis plus tard par le propriétaire : aucun n'est préféré.

- `cloudflare.mjs` : `renderHeaders(rules)` au format `_headers` de Cloudflare Pages (chemin sans
  indentation, puis `  Nom: valeur` indentés de deux espaces, ligne vide entre règles) et
  `renderRedirects(redirects)` au format `_redirects` (`/de /vers 301`).
- `netlify.mjs` : `render(rules, redirects)` → `netlify.toml` (blocs `[[headers]]` avec `for =` et
  `[headers.values]`, valeurs TOML échappées correctement ; `[[redirects]]` avec `from`, `to`,
  `status`, `force = true`).
- `vercel.mjs` : `render(rules, redirects)` → `{ headers: [{ source, headers: [{ key, value }] }],
redirects: [{ source, destination, statusCode }], trailingSlash: true, cleanUrls: false }` ;
  `/*` devient `/(.*)` et `/_astro/*` devient `/_astro/(.*)` (syntaxe `path-to-regexp` de Vercel).
- `nginx.mjs` : `render(rules, redirects)` → fragment `server { … }` à inclure : un `location`
  par règle, `add_header Nom "valeur" always;` pour **chaque** en-tête (nginx ne fait hériter les
  `add_header` que d'un niveau sans `add_header` : répète donc les en-têtes de `/*` dans chaque
  `location` plus spécifique), `return 301` pour les redirections, guillemets et `\` échappés,
  `location = /index.html` pour une redirection exacte.

Tests dans `adapters.test.mjs` (un seul fichier, découpe en helpers) : pour chaque adaptateur,
(a) chaque nom de `REQUIRED_HEADERS` est présent, (b) la valeur de la CSP est restituée à
l'identique (extrais-la de la sortie et compare), (c) la règle `/_astro/*` porte `immutable`,
(d) la redirection `/index.html → /` est présente, (e) les guillemets et caractères spéciaux sont
échappés (un en-tête de test avec `"` et `;`). Données : `buildRules` avec deux hachages
d'exemple. Limites d'`AGENTS.md` : fichiers ≤ 120 lignes, pas de `console`, pas de nombre magique.
