Composant `Photo` de `@paulperigault/astro` : **seule** façon d'afficher une image dans les sites
consommateurs. Lis d'abord `AGENTS.md`, `packages/astro/src/layout/Stack.astro` (props, `data-*`,
`:global()`), `packages/astro/src/media/{types,checks,presets,dominant}.ts` (à utiliser, sans
les modifier), `packages/astro/test/render.ts` et `packages/astro/test/Select.test.ts` (style
de test), et la doc de `<Picture>` dans `node_modules/astro` (version 7.4).

## Props (`AltProps & { … }` de `types.ts`)

`src: ImageMetadata` (import local, `assertLocal`) ; `alt` **ou** `decorative` (`altOf`) ;
`ratio?: Ratio` (absent = ratio intrinsèque de l'image) ; `focal?: Focal` (défaut `center`) ;
`priority?: boolean` ; `layout?: MediaLayout` (défaut `measure`) ; `kind?: MediaKind` (défaut
`photo`) ; `rule?: boolean` (filet média) ; `class?: string` (placement dans le parent).

## Rendu

```text
<div class="pp-media" data-ratio="landscape" data-focal="center" data-rule>
  <svg class="pp-media__placeholder" aria-hidden="true" focusable="false"><rect width="100%" height="100%" fill="#rrggbb" /></svg>
  <picture> <source type="image/avif" …> <source type="image/webp" …> <img …> </picture>
</div>
```

- `<Picture>` : `formats={FORMATS}`, `fallbackFormat={fallbackFormat(kind)}`,
  `widths={widthsFor(layout, src.width)}`, `sizes={sizesFor(layout)}`, `quality={qualityFor(kind)}`.
- `img` : `alt` (`""` si décorative), `width` et `height` **toujours** rendus ;
  `priority` → `loading="eager"` et `fetchpriority="high"` ; sinon `loading="lazy"` et
  `decoding="async"`.
- Placeholder : `dominantColor(imagePath(src))` au build. Couleur posée par l'attribut de
  présentation SVG `fill` (la CSP des sites refuse tout `style` en ligne, et `fill` n'est pas un
  style en ligne) ; si `undefined`, pas de `<svg>` et le fond `--pp-color-media-placeholder` du
  cadre suffit. **Aucun attribut `style`, aucun flou, aucun dégradé.**

## `frame.css` (importé par `Photo.astro`, réutilisé par les autres composants média)

Classes préfixées `.pp-media` (fichier global, pas de portée Astro). Cadre : `position:
relative`, `overflow: hidden`, `border-radius: var(--pp-media-radius)`, `background-color:
var(--pp-color-media-placeholder)`, propriétés logiques. `[data-ratio=…]` → `aspect-ratio:
var(--pp-ratio-…)`, l'image remplit le cadre (`inline-size`/`block-size: 100%`, `object-fit:
cover`) ; sans `data-ratio` : `block-size: auto`. `[data-focal=…]` → `object-position` par
**mots-clés** (`left top`…), jamais de pourcentage. `[data-rule]` → `border: var(--pp-media-rule)
solid var(--pp-color-line)`. Placeholder : `position: absolute; inset: 0`, sous l'image.

## Tests

`Photo.test.ts` (`renderDom`, image `./fixtures/sample.jpg`) : deux `<source>` AVIF puis WebP,
`img` avec `alt`, `width`, `height`, `sizes` = `sizesFor(layout)` ; décorative → `alt=""` ;
attributs `loading`/`fetchpriority`/`decoding` selon `priority` ; `data-ratio`/`data-focal` ;
`fill` au format `#rrggbb` ; aucun `style` dans tout le HTML ; `alt` vide → erreur ;
`expectTypeOf` sur les props (ni `alt` ni `decorative` refusé). `frame-css.test.ts` : lit
`frame.css` ; chaque `Ratio` et chaque `Focal` de `types.ts` a sa règle ; aucune valeur de
longueur ou de couleur brute (tout en `var(--pp-…)` ou mots-clés).
