Module `@paulperigault/tokens/contrast` (export déjà déclaré), ESM pur + `contrast.d.mts`. Il
s'appuie sur `./color.mjs` (déjà intégré) : le contraste se calcule sur la couleur **sRGB rendue**,
jamais sur le L d'OKLCH.

## API

- `relativeLuminance({ r, g, b })` (gamma, [0, 1]) → luminance relative WCAG 2.x
  (coefficients 0.2126 / 0.7152 / 0.0722, linéarisation par `gammaToLinear`).
- `contrastRatio(a, b)` : `a` et `b` sont des chaînes `oklch(…)`, `#rrggbb` ou des objets
  `{ l, c, h }` → rapport (1 à 21). Couleur hors gamut sRGB → `RangeError` (pas de rognage).
- `apcaLc(text, background)` : contraste APCA 0.0.98G-4g (Myndex), signé, **informatif
  seulement** (WCAG 3 n'a pas d'algorithme arrêté au 2026-09-10 ; jamais bloquant). Constantes
  nommées, source citée en commentaire.

## Tests

- `contrastRatio('#000000', '#ffffff')` = 21 (±1e-6) ; identiques = 1 ; ordre indifférent.
- `contrastRatio('#777777', '#ffffff')` ≈ 4.48 (2 décimales).
- `contrastRatio('oklch(0.215 0.016 270.7)', 'oklch(0.985 0.004 270.7)')` ≈ 16.79 (±0.05).
- Hors gamut → `RangeError`.
- `apcaLc('#000000', '#ffffff')` ≈ 106.04 (±0.1) ; `apcaLc('#ffffff', '#000000')` ≈ -107.88 (±0.1) ;
  `apcaLc('#888888', '#ffffff')` ≈ 63.06 (±0.2).
