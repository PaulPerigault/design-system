## Dialog

`<dialog>` natif modal. **Ouverture sans JavaScript** par l'API Invoker Commands
(`<button commandfor={id} command="show-modal">`) quand elle est disponible. N'écris **aucun** script : l'ouverture dans les navigateurs sans
Invoker Commands passera par un behavior livré plus tard ; documente-le dans le JSDoc. Props : `id`, `title` (`<h2>` relié par `aria-labelledby`), `closeLabel` (bouton de
fermeture `<form method="dialog">` + `<button>`), slot pour le corps, slot `actions`.
`closedby="any"` (fermeture par clic hors boîte, Chrome/Edge 134+, Firefox 141+, sans effet
ailleurs). Arrière-plan `::backdrop` sans flou, opaque à 60 % par `color-mix` sur
`--pp-color-fg` ; entrée par `@starting-style` sous `no-preference` seulement. Focus : le
navigateur le gère (premier élément focalisable) ; ne le surcharge pas.

Test `packages/astro/test/Dialog.test.ts` (`renderDom` de `./render`) : rôles, noms accessibles,
attributs selon les props et défauts, aucun attribut `style`.
