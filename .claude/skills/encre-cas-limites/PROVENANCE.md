## Modifications

- Traduction en français, réduction à moins de 150 lignes ; catalogue condensé (noms, identifiants,
  libellés, nombres, collections, temps, médias, états, environnement) ; adresses en `example.org`.
- Retirés : la phrase d'accueil imposée, la bascule « Demo data / Worst case » (remplacée par une
  fixture de test), le masque dégradé, la virtualisation, les six phases du flux d'origine.
- Ajoutés : la section « Surcharges Encre », les propriétés logiques, les jetons `--pp-*`, la liste
  avant livraison réécrite pour le web statique (la source ui-ux-pro-max vise le mobile natif).
- Aucun script, hook, fichier de données ni catalogue de styles de la source n'est repris.
